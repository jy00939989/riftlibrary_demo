# 归墟图书馆 · AIGC 大赛演示视频拍摄执行手册

> 基于 `aigc-demo-video-script.md` 细化，目标：让你拿到就能拍，拍完就能剪。> 总时长：85 秒 · 画幅：16:9 横屏 · 分辨率：1080p 或 4K

---

## 一、先别拍，先把游戏调到「可录屏状态」

这一步 10 分钟，能省去后面 80% 的返工。

### 1.1 开一个「演示专用」存档（或清空当前存档）

大赛视频要展示的是**理想流程**，不是真实游玩进度。建议：
- 用浏览器无痕模式打开游戏
- 或者新建一个专门用于拍摄的 localStorage 键（如果你会改代码，可以让克克帮你做一个「演示模式」按钮）
- 最低要求：确保录屏时界面干净、没有弹窗遮挡、没有未读红点

### 1.2 游戏内需要提前准备好的画面状态

| 画面 | 准备方法 |
|---|---|
| 废墟图书馆（氛围阶段 1） | 新存档直接就是，或把 atmosphere 调到 0 |
| 温暖图书馆（氛围阶段 3-4） | 用 `addAtmosphere` 控制台加到 160-300 |
| 星辰之境（氛围阶段 5） | 用 `addAtmosphere` 控制台加到 500 |
| 缮写室有书可选 | 确保有 3-5 本未开始的书，推荐《小王子》《图书馆指南》《动物农场》 |
| 访客能触发 | 把时间调到白天，确保有访客在馆 |
| 王小磊/沈明远/程远在馆 | 如果没有，刷新或等待；或让克克写一段强制触发代码 |

> 不会调？把这段发给克克：「帮我做一个演示模式，一键设置 atmosphere=500、生成访客王小磊、重置所有书为未抄写状态」。

### 1.3 录屏设置

- **工具**：OBS / 浏览器全屏录制 / Win+G 游戏栏
- **画幅**：16:9，建议 1920×1080
- **帧率**：30fps 足够
- **鼠标**：录屏时建议隐藏鼠标，或保持缓慢移动
- **字体/UI**：浏览器缩放调到 100%，不要开系统深色模式

## 三、拍摄当天最小行动清单

如果你只能挤出 1 小时，按这个顺序做：

- [ ] 0-10 分钟：打开游戏，把氛围调到 500，确认有访客
- [ ] 10-25 分钟：拍完镜头 1、2、3、4（这 4 条是核心，其他可以补）
- [ ] 25-40 分钟：拍镜头 5（五阶段切换）
- [ ] 40-50 分钟：录屏收藏室滑动
- [ ] 50-60 分钟：把所有素材拖进剪映/必剪，按脚本顺序排一遍

先拼出**一版能看的粗剪**，再优化细节。不要第一轮就抠细节。

## 五、剪辑顺序（剪映/必剪/PR 通用）

1. 新建 16:9 项目，导入所有素材
2. 按镜头 1-7 顺序拖入时间线
3. 先关声音，把画面长度调到脚本时间
4. 导入旁白，按时间轴对齐
5. 加 BGM，音量压到旁白的 20-30%
6. 加字幕（中英双语）
7. 加淡入淡出转场
8. 导出 1080p MP4
