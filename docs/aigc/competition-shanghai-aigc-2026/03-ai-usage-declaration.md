# 归墟图书馆 · AI 使用声明

## 一、声明目的

本声明用于说明《归墟图书馆》（Rift Library: The Gui Xu Collection）在开发过程中使用 AI 工具的情况，确保所有生成内容合法、合规、授权清晰，符合第四届上海国际 AIGC 创新大赛的参赛要求。

---

## 二、AI 工具使用情况总览

| 使用环节 | AI 工具 | 使用方式 | 人工介入程度 |
|---|---|---|---|
| 访客叙事文案 | Claude / Kimi / GPT | 生成初稿、扩展变体、润色建议 | 高：人工筛选、改写、统一语气、校对 |
| 游戏策划文档 | Claude / Kimi | 头脑风暴、结构建议、可行性评估 | 高：人工决策、删改、定稿 |
| 代码辅助 | Claude Code | 代码生成、重构建议、bug 排查 | 高：人工审阅、测试、调整 |
| BGM 音乐 | Suno | 基于古典名曲（维瓦尔第、德沃夏克等，已进入公有领域）进行风格化改编 | 中：人工挑选、剪辑、循环处理 |
| 书籍封面图 | Nano Banana / GPT Image / 其他图像生成工具 | 根据书籍主题生成封面 | 中：人工筛选、修图、统一风格 |
| 植物立绘/场景图 | AI 图像生成 + 手工修图 | 生成植物生长阶段图像 | 中：人工筛选、修图 |
| 图标/装饰素材 | Emoji / 开源图标 / AI 生成 | 部分 UI 装饰使用 emoji 和开源图标 | 低 |

---

## 三、公有领域与授权说明

1. **古典音乐改编**
   - 原曲（维瓦尔第《四季》、德沃夏克《自新大陆》等）已进入公有领域。
   - Suno 生成的改编版本仅用于本游戏 Demo 展示，未声明对原曲的著作权。

2. **开源与第三方资源**
   - Tailwind CSS：MIT 协议
   - Supabase JS SDK：MIT 协议
   - 其他图标/字体：使用开源协议或系统默认字体

3. **原创资产**
   - 游戏系统设计、数值平衡、交互流程为团队原创。
   - 经过人工精修的叙事文案视为本项目原创成果。

---

## 四、人工创作占比说明

- **核心玩法与系统设计**：100% 人工
- **程序代码**：约 80% 人工编写，20% AI 辅助生成/重构
- **叙事文案**：约 60% 人工精修，40% AI 生成初稿
- **视觉资产**：约 50% 人工筛选修图，50% AI 生成
- **音乐资产**：约 30% 人工剪辑处理，70% AI 生成

---

## 五、合规承诺

1. 本作品不含有违反国家法律法规的内容。
2. 本作品不侵犯任何第三方著作权、肖像权、商标权。
3. 所有 AI 生成内容均经过人工审核，确保符合公序良俗。
4. 参赛者对提交内容的真实性、合法性负责。
