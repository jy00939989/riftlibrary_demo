# 归墟图书馆 · 玩法说明

## 一、游戏定位

《归墟图书馆》是一款**纯前端 Web 游戏**，核心循环是：

```
专注计时 → 获得资源 → 修复图书馆 → 收集书籍 → 触发访客叙事 → 解锁深层内容
```

它同时是一个**桌面陪伴型番茄钟工具**：玩家每次专注都会推动游戏世界发生微小但可见的变化。

---

## 二、核心玩法机制

### 1. 专注誊抄（番茄钟）

- 玩家在缮写室选择一本书，开始 25/45 分钟或自定义时长的专注。
- 专注过程中，屏幕显示书写动画与当前书籍进度。
- 完成后根据时长获得：
  - **智慧之光**（coins）：通用货币
  - **氛围**（atmosphere）：图书馆整体修复进度
  - **字数**（words）：累计成就与里程碑
  - **灵感**（inspiration）：稀有资源，可兑换补充包等

### 2. 图书馆经营

- 用智慧之光购买新书、升级书架容量、提升借阅区等级。
- 氛围值影响图书馆视觉阶段：
  - 0~30：荒废废墟
  - 30~80：破败但可用
  - 80~160：温馨小屋
  - 160~300：华丽殿堂
  - 300~500：星辰圣殿
- 不同阶段解锁不同 BGM 与背景图。

### 3. 访客系统

- 访客随机到访，每位访客有独特的借书偏好与叙事线。
- 借书 → 归还 → 触发叙事事件 → 提升好感度。
- 好感度达到阈值后解锁偶层、稀层、终局事件，赠送纪念品与限定书籍。

### 4. 书籍收集

- 书籍分为普通书与长书分卷（多卷本）。
- 每本书可多次誊抄提升熟练度（最高 Lv5）。
- 部分书籍为 DLC 补充包内容，可用灵感解锁。

### 5. 植物系统

- 三种异世界植物：鹤望兰、魔法玫瑰、星光蕨。
- 浇水、施肥、收获，获得种子。
- 种子可兑换限定书籍、氛围、灵感或其他植物种子。

### 6. 每日任务与成就

- 每日馆务：专注 25 分钟、还书、浇水。
- 30 个成就覆盖专注、收集、访客、重建四大维度。

## 三、操作说明

| 操作 | 说明 |
|---|---|
| 开始专注 | 选择书籍 → 选择模式 → 点击「开始专注」 |
| 暂停/继续 | 专注中点击「暂停」 |
| 完成专注 | 点击「完成」提前结束，或等待倒计时结束 |
| 购买书籍 | 进入商店，用智慧之光购买 |
| 升级设施 | 商店 → 图书馆升级 |
| 查看访客 | 访客页查看到期、叙事、好感度 |
| 切换音乐 | 顶部 🎼 按钮打开音乐选择器 |

## 四、技术特点

- **纯前端实现**：HTML + Tailwind CSS + Vanilla JS（ES Modules）。
- **本地存档**：localStorage 保存进度，支持导入导出。
- **云端同步（可选）**：Supabase 后端支持登录与跨设备同步。
- **响应式设计**：适配桌面与移动端。
- **AIGC 工作流**：
  - 访客叙事文本：Claude / Kimi 生成 + 人工精修
  - BGM：Suno 基于古典名曲改编
  - 封面图：AI 图像生成 + 人工修图
