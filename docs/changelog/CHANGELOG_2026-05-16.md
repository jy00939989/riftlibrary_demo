## 田园瘟疫纪事 · 设定草稿

### 世界观
中世纪西方架空位面，田园牧歌初期，带着愚昧的影子。瘟疫爆发后，五位角色齐心合力用图书馆的知识治好了瘟疫，从此走上知识之路。

### 五位核心角色
| 角色 | 身份 | 弧线 |
|------|------|------|
| 小艾拉 👧 | 普通孩子 | 从读童话到成为草药师助手 |
| 玛格丽特 🌿 | 草药师 | 被排斥到被尊敬 |
| 杜兰伯爵 ⚔️ | 领主 | 从封城到开放 |
| 艾德里安 📖 | 年轻学者 | 从偷读到公开倡导 |
| 卡特琳修女 🕯️ | 流浪修女 | 从祈祷到行动 |

### 五幕结构
1. 初遇孩子 — 传送门开启，小艾拉偶然穿过裂缝
2. 草药师与愚昧 — 玛格丽特被排斥，领主封城
3. 瘟疫蔓延 — 卡特琳和艾德里安的抉择
4. 知识即解药 — 合力研究，馆长誊抄关键书籍
5. 曙光 — 瘟疫消退，位面进入建设期

### 故事开端（讨论中）
小艾拉在森林里寻找食物，看到一栋破旧小石屋——这是她以前从没见过的。她好奇地推开门……

### 访客机制
- 角色作为访客出现在归墟主馆（被命运选中穿过裂缝）
- 故事通过语录、信件、还书对话推进
- 信件收藏在馆长办公室→收藏室→位面档案中
- 触发方式：挂在现有事件钩子上（visitor_arrive/return/focus_complete/book_complete/atmosphere_stage）
- 不新增事件类型，低耦合复用 achievements.js 模式
