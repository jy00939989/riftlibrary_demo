## 🆘 备用方案

| 风险 | 应对 |
|------|------|
| CDN 没加载（Tailwind/字体/html2canvas） | 提前 30 秒打开页面等着 |
| PV 不播放 | 本来就是点击才播，点了就行 |
| BGM 不响 | 点右上角 🔈/🔇 切换，或点画面任意位置 |
| 缮写动画卡顿 | 刷新页面重新来过 |
| Dev 操作失误 | `Ctrl+Shift+D` 随时重开 |
| 时间超了 | 压缩 Phase 3/4，女儿的故事不能丢，收尾话术必须完整 |
