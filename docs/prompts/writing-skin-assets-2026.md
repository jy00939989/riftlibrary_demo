# 缮写室底版皮肤素材提示词（2026-10-30）

关联实现：`data/writing-skins.js` + `css/style.css` 皮肤变量块（`[data-writing-skin='...']`）
技术口径：CSS `background: url(...) center/cover` **逐页裁切**——每张图会被左页右页各裁一次，
所以要求：**满版纹理、视觉重心居中、四边可裁、无方向性文字**。
命名：`visual/writing/skin_<id>_pages.png`（gothic / chinese / manuscript / oilpaint）
优先级：哥特、中国风（兜底是纯渐变最缺图）＞ 手抄本、油画风（兜底已接近成品）

---

## ① 哥特之夜 skin_gothic（最优先）

```
缮写室书页底图，单页竖向构图，满版纹理设计，深紫黑色夜空质感纸张（#1a1426基调），
极 subtle 的烫银藤蔓花纹只出现在四边边框带（左右各8%边距、上下各10%边距内保持绝对干净无花纹），
四角有微微的银色卷草装饰，纸张带轻微做旧斑驳和重暗角（四边渐暗15%），
整体氛围幽暗静谧，适配银白色文字，无任何文字任何插画，纯背景纹理，
克苏鲁式克制的哥特装饰风，不要恐怖元素，PNG，高细节
```

## ② 中国风 skin_chinese（最优先）

```
缮写室书页底图，单页竖向构图，满版纹理设计，仿古洒金宣纸质感（米白暖调 #f7f0dd），
纸面随机散布极细腻的金箔碎屑斑点（稀疏、微小、大小不一），
边缘做淡淡的赭石色晕染仿古旧，上下各10%边距内可有一条极细的朱红色栏线暗示（淡、细、居中偏内），
中央书写区绝对干净素净，无任何文字任何印章任何插画，纯纸张纹理，
宋代文人纸意，清雅克制，PNG，高细节
```

## ③ 中世纪手抄本 skin_manuscript（次优先）

```
缮写室书页底图，单页竖向构图，满版纹理设计，中世纪泥金装饰手抄本羊皮纸（暖金黄调 #e6cf96），
四边有泥金藤蔓与几何装饰边框带（克制、扁平、拜占庭式），
边框带外侧可极淡暗示红黑双色首字母装饰位但不含字母，
纸张有明显羊皮纤维肌理与岁月斑驳，中央书写区干净仅留 faint 横线格暗示，
无任何可辨认文字，纯背景纹理，PNG，高细节
```

## ④ 油画风 skin_oilpaint（次优先）

```
缮写室书页底图，单页竖向构图，满版纹理设计，古典油画布面肌理（暖褐米调 #d9c8a4），

PNG，高细节
```

## 验收清单（克克收件时逐项对）

- [ ] 满版纹理、视觉重心居中（左页右页各裁一次都不穿帮）
- [ ] 四边安全区干净：左右 8%、上下 10% 内无花纹无装饰
- [ ] 无任何文字/字母/数字（AI 乱码文字一律打回）
- [ ] 命名 `skin_<id>_pages.png` 落 `visual/writing/`
- [ ] 收图后把 css/style.css 对应皮肤块注释里的 `url(...)` 取消注释层叠即可换图
