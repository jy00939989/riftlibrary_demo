# 缮写室底版皮肤素材提示词（2026-10-30 v2）

关联实现：`data/writing-skins.js` + `css/style.css` 皮肤变量块（`[data-writing-skin='...']`）
技术口径 v2（图南指正）：**对开双页整幅横版**——桌面端是摊开的书（左右两页横排），
CSS 用 `background-size: 200% 100%` + 左右 position split，**左页取图左半幅、右页取右半幅**；
手机单页模式自动显示右半幅，一套图两端适配。图到之前 CSS 手绘渐变兜底已生效。
命名：`visual/writing/skin_<id>_pages.png`（gothic / chinese / manuscript / oilpaint）
优先级：哥特、中国风（兜底是纯渐变最缺图）＞ 手抄本、油画风（兜底已接近成品）

---

## 统一规格（四张通用）

- **尺寸：2400×1600 横版（3:2）**，对开双页一整张
- **构图**：正中央留一条书脊带（宽约 3%，微微内阴影/烫线），左右两半各是一页
- **每半页的安全区**：该半页内左右各 8%、上下各 10% 无花纹无装饰（文字落点）
- 纹理满版、视觉重心在每半页中心（split 裁切后单页不穿帮）
