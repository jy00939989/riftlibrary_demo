## 零、通用前缀（每次生成前复制）

```text
请为网页游戏《归墟图书馆》生成一个 UI 素材。

整体风格：Gust《炼金工房》(Atelier) 系列 + 《仙境传说 RO》，水彩手绘，暖色调，手绘描边，材质感强。
世界观：一座从废墟重建到星辰阶段的异世界图书馆，有古籍、羽毛笔、蜡烛、黄铜灯具、木质书架、魔法微光。

色彩规范：
- 羊皮纸底色 #f5e6c8，暗部 #e8d5a8
- 文字/墨水 #2c2419，次要文字 #5c4d3c
- 魔法金 #c9a227（边框、高光、主按钮）
- 木材 #8b6914（书架、标签、暗部）
- 魔法蓝 #4a7c9b（访客、进度条、位面）

技术要求：
- 透明底 PNG，元素居中，周围留白 ≥20%
- 至少 2x/4x 高清，建议画布 1024×1024 或 2048×2048
- 便于后期切割，同一画布内不要多个元素重叠遮挡
- 无文字（除非特别说明），边缘柔和
- 避免：纯扁平、霓虹色、科幻直线、哥特暗黑、血腥
```
