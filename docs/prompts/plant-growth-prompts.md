# 归墟图书馆植物成长阶段生成提示词（sprite sheet 版）

> 用途：每种植物生成一张图，内含 5 个成长阶段，游戏内按格子切割使用。
> 风格总纲：Gust《炼金工房》系列 + RO 仙境传说，水彩手绘，暖色调羊皮纸，透明底 PNG。

---

## 零、通用前缀（每次生成前复制）

```text
请为网页游戏《归墟图书馆》生成一张植物成长阶段图。

整体风格：Gust《炼金工房》(Atelier) 系列 + 《仙境传说 RO》，水彩手绘，暖色调，手绘描边，材质感强。
世界观：一座从废墟重建到星辰阶段的异世界图书馆，盆栽摆放在木质窗台或古铜花架上。

色彩规范：
- 羊皮纸/墙面底色 #f5e6c8，暗部 #e8d5a8
- 陶盆主体 #b87d4b，裂纹处 #8b5a2b，苔藓点缀 #6b8e5a
- 植物主色按种类区分
- 魔法金 #c9a227（高光、边框、微光粒子）
- 魔法蓝/银 #7fa3b5（星光蕨微光）

技术要求：
- 透明底 PNG，画布 1280×256px（5 格，每格 256×256px）
- 5 个阶段从左到右等距排列，每格居中，周围留白 ≥15%
- 每格内植物比例一致，便于程序按 256px 宽度切图
- 无文字，边缘柔和，同一画布内格子互不重叠遮挡
- 避免：纯扁平、霓虹色、科幻直线、哥特暗黑、血腥
```

## 一、鹤望兰（bird_of_paradise）成长阶段图

```text
生成鹤望兰成长阶段 sprite sheet，5 个阶段从左到右排列：

1. 幼苗（Lv.1）：刚从陶土裂缝中探出的一对小嫩芽，高约 1/4 格，嫩绿色，带一点卷曲。
2. 小株（Lv.2）：3–4 片细长小叶从中心展开，高度约 1/3 格，叶脉清晰，陶盆裂纹和苔藓可见。
3. 茂叶（Lv.3）：叶片变宽变长，如鹤翅般向两侧优雅伸展，高度约 1/2 格，深绿色带光泽。
4. 含苞（Lv.4）：叶片丰茂，中央挺出一支修长花茎，顶端有橙蓝相间的尖形花苞，高度约 2/3 格。
5. 绽放（Lv.5）：高挑花叶完全舒展，花苞绽放成鹤望兰标志性的橙蓝羽状花朵，姿态优雅，高度占满格子，几片金色微光花粉飘落。

陶盆统一为旧陶土盆，侧面有裂纹和青苔，底部托着一圈暖棕色泥土。
整体色调：翠绿 + 暖橙 + 天蓝花苞 + 古铜陶盆。
```

## 二、魔法玫瑰（magic_rose）成长阶段图

```text
生成魔法玫瑰成长阶段 sprite sheet，5 个阶段从左到右排列：

1. 幼苗（Lv.1）：深色泥土中冒出两片带暗红边缘的小子叶，茎上已有细小尖刺，高度约 1/4 格。
2. 小株（Lv.2）：主茎变粗，长出 3–4 片深绿锯齿叶，叶背泛着暗红，高度约 1/3 格，刺更明显。
3. 茂叶（Lv.3）：枝叶向四周展开，叶片浓密，颜色深绿近紫，高度约 1/2 格，隐约可见藤蔓缠绕感。
4. 含苞（Lv.5）：茂叶丛中挺出一颗暗红色花苞，花瓣紧闭，缝隙间漏出柔和紫光，高度约 2/3 格。
5. 绽放（Lv.5）：一朵暗红玫瑰完全盛开，花瓣边缘微卷，花心散发淡紫色魔法微光，几片花瓣轻轻飘落，高度占满格子，神秘而高贵。

陶盆统一为深色石质花盆，表面有低调的古铜符文刻痕，泥土偏黑褐。
整体色调：暗红 + 深紫 + 墨绿 + 淡紫微光。
```

## 三、星光蕨（starlight_fern）成长阶段图

```text
生成星光蕨成长阶段 sprite sheet，5 个阶段从左到右排列：

1. 孢子（Lv.1）：陶盆泥土表面散落着银色细小孢子，中央鼓起一小团银灰色绒芽，高度约 1/5 格，像沉睡的星尘。
2. 嫩芽（Lv.2）：几根卷曲的银色蕨芽从孢子团中钻出，像婴儿的拳头，高度约 1/3 格，尖端泛着微光。
3. 舒展（Lv.3）：蕨叶逐渐展开，羽状复叶轮廓清晰，叶片正面深绿、背面银白，高度约 1/2 格。
4. 流光（Lv.4）：叶片完全舒展，边缘和叶脉开始泛出银色流光，像有星光在叶脉中缓慢流动，高度约 2/3 格。
5. 星瀑（Lv.5）：整株蕨类茂盛如伞，叶片上流淌无数银色光点，部分光点像坠落星河一样飘向下方，高度占满格子，梦幻而宁静。

陶盆统一为带青绿色铜锈的金属盆，盆口有一圈细小花纹，泥土偏深褐带银灰苔藓。
整体色调：深绿 + 银白 + 淡蓝微光 + 青绿铜锈。
```

## 四、空花盆（共享状态）

```text
生成一个空花盆素材：
- 尺寸：256×256px
- 陶土或石质花盆，表面有自然裂纹、青苔斑驳
- 盆内露出松软的深褐色泥土，插着一把迷你园艺小铲子
- 整体姿态微微倾斜，透露出一丝落寞但治愈的闲置感
- 透明底，元素居中，周围留白 ≥20%
- 风格：水彩手绘，暖色调，边缘柔和
```

## 五、使用方式

生成后按 256×256px 每格切图，命名对应 `data/plants.js` 中的 `art` 字段：

```
visual/plants/bird_of_paradise_lv1.png  ~ lv5.png
visual/plants/magic_rose_lv1.png        ~ lv5.png
visual/plants/starlight_fern_lv1.png    ~ lv5.png
visual/plants/empty_pot.png
```

## 六、生成优先级建议

1. **第一批**：鹤望兰（植物系统默认/新手向，色调最温和）
2. **第二批**：魔法玫瑰（暗色调，验证微光效果）
3. **第三批**：星光蕨（银色流光，验证魔法粒子表现）
4. **最后**：空花盆（三种植物收获后共用）
