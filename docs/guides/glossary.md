# 异世界图书馆 · 名词对照表 / Glossary

## 核心系统 / Core Systems

| 中文 | English | 说明 / Note |
|------|---------|-------------|
| 异世界图书馆 | Isekai Library | 游戏标题，也可译作 Library of the Void / Rift Library |
| 归墟图书馆 | Guixu Library | 图书馆正式名称，"归墟"出自《列子》，意为万物归宿之深渊 |

| 读者沙龙 | Reader Salon | 访客中心页面 |
| 馆史档案 | Archive | 历史记录/墨墨日志/位面 页面 |
| 位面商店 | Plane Shop | 商店页面 |
