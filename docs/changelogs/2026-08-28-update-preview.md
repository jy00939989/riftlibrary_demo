# 归墟图书馆 · 8 月下旬更新预告

---

## ✨ 本次重点优化

### 1. 全站提示统一为温和 Toast

以前买书、升级、解锁时失败会弹原生 `alert` 阻断操作，现在统一变成底部滑出的红色/金色小提示，不跳戏、不挡内容。

涉及场景：余额不足、手稿盒已满、灵感不够、环境音未解锁、修复室升级失败等。

### 2. 限量挂牌获得仪式感

获得「先驱者的墨印」或「开馆纪念牌」时，会弹出专属感谢弹窗，带挂牌大图和一段来自图书馆的致谢——因为你不只是玩家，也是这座图书馆的同行者。

### 3. 古籍修复室文案补全

修复室解锁/升级时不再显示 `restorationNarrative0` 这类 key 名，而是正常的叙事文案，从废墟到圣堂，每级都有对应描述。

### 4. 大书架重抄更顺手

- 已完成书籍的卡片上直接显示 **「解锁重抄 · 1 灵感」** 按钮，不用先点进弹窗再找按钮。
- 点击书籍弹出的「典藏档案」移除过时的 Lv1–Lv5 进度条，改为直接展示作者小传、创作轶闻、书评和典藏封面。

### 5. 项目规划器支持待办分条导入

`riftlib-planner` 现在能自动把 `_todo-index.md` 里的 `- [ ]` 待办拆成独立条目，分类分条显示在月视图/看板/列表里，方便跟踪后续开发节奏。
