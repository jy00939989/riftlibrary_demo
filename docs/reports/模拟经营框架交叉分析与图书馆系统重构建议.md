# 模拟经营框架交叉分析与图书馆系统重构建议

> 基于豆包《番茄钟放置游戏设计指南》+ 模拟经营入门指南 × 图书馆当前状态
> 日期：2026-05-27

## 一、图书馆的模拟经营本质

用模拟经营的核心公式来审视图书馆：

```
进货 ──→ 加工 ──→ 出售 ──→ 升级
  │         │         │         │
选书/解锁   专注誊抄   上架/借阅   设施升级
```

四个环节的当前健康度：

| 环节 | 模拟经营标准 | 图书馆现状 | 健康度 |
|------|------------|-----------|--------|
| 进货 | 资源获取方式多样化，有策略选择 | 商店买书 + 种子兑换 + 访客赠书，方式够多 | 🟢 健康 |
| 加工 | 可有多次加工提升价值 | 一次誊抄 = 直接完成，无深度加工 | 🟡 偏薄 |
| 出售 | 将产品转化为收益的核心环节 | **访客借阅半瘫痪**（Lv0 天花板），书籍上架后无后续 | 🔴 断裂 |
| 升级 | 提供策略性和成长感 | 纯数值增长，无分支无 trade-off | 🟡 偏薄 |

**核心诊断：图书馆的"出售"环节断了。** 玩家花 25 分钟抄完一本书→上架→然后呢？书就只是放在那里。访客借阅系统本该是这个环节的引擎，但它被 Lv0 天花板卡住了。

## 二、你提到的几个具体问题，逐一分析

### 2.1 大书库逻辑：「未完成的书不该上架」

你说得完全对，而且这恰好是模拟经营框架里"加工→出售"环节的核心概念：

> 加工中的半成品和可出售的成品应该在**不同的空间**里。

当前问题：大书库（成品展示区）混入了未抄完的书（半成品），这等于把厨房的备菜台和餐厅的展示柜混在一起。

**建议方案**：

```
缮写室（加工区）          大书库（成品展示区）
├── 进行中的书             ├── 已完成的书籍（书脊展示）
├── 已解锁待抄的书          ├── 按分类/完成时间排列
└── 任务目标书（位面）      ├── 「策展模式」：玩家可拖拽排列
                           └── 读者可浏览/借阅
```

具体改动：
- **缮写室新增「待抄书架」**：展示所有已解锁但未开始/未完成的书籍，点击开始专注
- **大书库只保留已完成书籍**：书脊卡片 + 完成日期 + mastery 等级
- **完成一本书 = 从缮写室"搬家"到大书库**，配合上架动画（已有典藏证书，可简化复用）

这同时解决了你上回说的"书库获得感和逻辑有问题"——完成的书出现在书架上，是一种可视化的、有仪式感的成果积累。

### 2.2 收集品/成就应有实际效果

豆包原则 4 的核心论点，你认可这个方向。具体到图书馆：

**成就 → 誊抄加成系统**

| 成就类型 | 解锁效果 | 设计意图 |
|---------|---------|---------|
| 完成第一本书 | 誊抄速度 +3% | 新手激励 |
| 完成 5 本书 | 解锁"速读"：15 分钟短番茄模式 | 给老玩家减负 |
| 完成 10 本书 | 缮写室背景升级 | 视觉成长 |
| 全分类各完成 1 本 | 解锁"杂学家"buff：跨分类抄书 +10% 灵感 | 鼓励多元阅读 |
| 单本书 mastery Lv5 | 该书书灵觉醒（见火花 5） | 深度投入的终极奖励 |

**关键**：玩家可以在多个成就路线中选择优先攻克哪个，形成"分支选择"——你是想先广度（各分类各一本）还是先深度（一本书刷到 mastery Lv5）？

### 2.3 访客 buff 化

模拟经营框架中，访客/顾客本身就是"出售"环节的核心。但图书馆的访客目前只是来借书还书，没有差异感。

**建议：每位访客一个被动光环**

| 访客 | 光环 | 激活条件 | 设计意图 |
|------|------|---------|---------|
| 沈明远 | 哲学类速度 +10% | 在馆时自动生效 | 学者 buff |
| 艾拉 | 童话类氛围收益 +15% | 在馆时自动生效 | 小女孩的感染力 |
| 阿九 | 商店刷新 +1 个商品 | 到访后持续 24h | 商人实用 buff |
| 待定第 4 位 | 诗歌类灵感收益 +20% | 在馆时自动生效 | 差异化 |

**进阶**：访客好感度达到不同等级，光环效果增强。满级解锁信物后，信物提供永久被动（即使访客不在馆也生效）。

### 2.4 多线程专注

模拟经营里有一个概念叫"多次加工"——同一个原材料经过多道工序，价值逐步提升。对应到图书馆：

**当前流程（单线程）**：
```
选一本书 → 专注 25 分钟 → 进度 +2500 字 → 重复
```

**多线程流程**：
```
同时推进 2-3 本书（不同位面/不同分类）
├── 主线书：大书库目标书，追求完成
├── 位面任务书：为田园位面角色誊抄特定章节
└── 自由书：随便抄，探索新分类
```

- 同一个番茄钟，产出分散到不同书上
- 玩家决定"今天 25 分钟分配给哪本书"
- 不同书关联不同系统（位面任务 / 访客好感 / 成就进度），选择有意义

**这个设计直接回应了豆包原则 1「玩家必须是决策者」**——每个番茄钟开始前，玩家要做一个资源配置决策。

## 三、从模拟经营框架中补充的新视角

### 3.1 目标系统：当前缺少「直接目标」

模拟经营报告指出，游戏需要有一个明确的直接目标驱动玩家反复执行核心循环。图书馆的现状：

- **直接目标**：无。玩家打开后不知道"我要做到什么程度才算赢"
- **潜在目标**：收集全部书籍、全访客满好感、氛围 500——但这些都是隐性的

**建议**：在馆长办公室的「概况」页加一个明确的当前大目标：

```
🏛️ 当前目标：将归墟图书馆从「废墟」恢复至「星辰之境」
├── 阶段 1/5：废墟 → 破败（氛围 30）  ← 当前
├── 阶段 2/5：破败 → 陈旧（氛围 80）
├── ...
└── 阶段 5/5：温暖 → 星辰（氛围 500）
```

这个目标一直存在，玩家随时知道自己"在哪"和"往哪走"。

### 3.2 时间系统：图书馆的独特优势

模拟经营报告讨论了时间循环。图书馆有一个大多数模拟经营游戏没有的东西：**真实时间**。

番茄钟 25 分钟不是游戏时间，是**玩家的真实时间**。这意味着：

- 每一天的专注都是真实的投入
- 进度是有重量的——你抄了 3000 字，那是你真的坐了 25 分钟
- 这个重量感是图书馆最大的差异化优势

**但同时**，真实时间的成本意味着：玩家的每一次专注都必须感到"值"。如果抄了 25 分钟只得到几个数字，玩家不会来第二次。

### 3.3 装修系统：休息时间的天然载体

模拟经营报告提到装修是"消耗货币、缓解后期无聊"的手段。你之前提过的**造景贴纸/拖拽家具**正好落在这里。

结合豆包原则 2（休息时间要有决策），图书馆的休息时间可以做的事：

| 休息时间行动 | 消耗 | 收益 | 类型 |
|------------|------|------|------|
| 给植物浇水 | 浇水机会 | 植物成长 | 养成 |
| 整理书架策展 | 无 | 排列加成效果 | 策略 |
| 和访客聊天 | 无 | 好感度 + 解锁对话 | 叙事 |
| 查看墨墨日志 | 无 | 回顾成就感 | 情感 |
| 逛商店 | 智慧之光 | 升级/新书 | 经营 |

**关键**：每一项都是 1-2 分钟能完成的微型互动，不打断休息节奏，但让休息时间有了内容。

## 六、一句话总结

> 模拟经营框架告诉你「结构该怎么搭」，豆包报告告诉你「玩家为什么会留下来」，两份合在一起指向同一个结论：**图书馆的加工环节（专注誊抄）够好，但出售环节（书的价值兑现）需要重建——书籍上架不是终点，书被借阅、被讨论、产生涟漪，才是图书馆活起来的标志。**
