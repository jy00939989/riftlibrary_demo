# 异世界图书馆 - 留存设计方案 v1.0

---

## 一、开场设计（0-65秒）

### 核心原则

**1. 60秒关键行为法则**
- 所有高留存应用的共同点：用户必须在前60秒内完成一次"关键行为"
- 对于异世界图书馆，关键行为就是：完成第一次专注，抄完第一页书

**2. 第一次专注加速机制**
- 首次专注使用100倍加速，25分钟专注 ≈ 15秒即可完成
- 让用户立刻体验"专注→获得成果"的正反馈闭环
- 正常模式恢复真实时间

---

### 精简版开场流程

**【0-30秒】开门**
- 画面：破旧的图书馆大门，门上发光的字：「每一次专注，都是一次重建」
- 弹出简单对话框：
  > 欢迎来到异世界图书馆。
  > 这里曾藏有千万世界的故事，如今已是一片废墟。
  > 你每专注抄写一页，就能让这里的一本书重新苏醒。
- 只有一个按钮：**[开始抄写]**

**【30-65秒】直接开始 + 15秒加速完成**
- 点击后直接进入专注界面，新手教学模式：
  > 💫 **时间魔法启动！**
  > 第一次抄写，时间流速将加快100倍
  > 25分钟专注 ≈ 15秒即可完成
  > （正常模式恢复真实时间）
- 15秒后展示成果：
  > ✅ **抄写完成！**
  > 你成功抄写了第一页
  > 《希腊神话故事》已苏醒 1/100 页
- 展示解锁动画：书架上一本书微微发光，书页轻轻翻动一下

---

### 三个留存钩子（65秒后）

离开时弹出，让用户带着"未完成感"离开：

1. **📚 书籍层钩子**："还有99页即可完全解封《希腊神话故事》"
2. **👤 访客层钩子**："第一位访客还有3次专注就会到来"
3. **🏛️ 建筑层钩子**："修复缮写室还需要5次专注"

最后提示：
> 下次回来继续抄写，重建这座图书馆吧～
> [继续抄写] [先离开]

## 二、大书库可视化系统

### 书架整体布局设计

```
┌─────────────────────────────────────────────┐
│  书库总览：已解封 3/20 本 | 修复度 15%    │
├─────────────────────────────────────────────┤
│                                             │
│  [书架01]  [书架02]  [书架03]  [书架04]    │
│  □□□□□□    □□□□□□    □□□□□□    □□□□□□     │
│  □■□□□□    ■■■□□□    □□□□□□    □□□□□□     │
│  □□□□□□    □□□□□□    □□□□□□    □□□□□□     │
│                                             │
│  [书架05]  [书架06]  [书架07]  [更多...]   │
│                                             │
└─────────────────────────────────────────────┘
```

- □ = 空位（尚未解锁的书籍位置）
- ■ = 有书（已解封的书籍）
- 每个书架放15本书，分3层×5本

---

### 书籍上架动画（5步仪式感设计）

当用户抄完最后一页，不是直接显示"完成"，而是：

1. **书页发光**：正在抄写的页面金光慢慢扩散
2. **书籍凝聚**：光粒子从书页飞向书库的对应空位
3. **生成动画**：一本小小的书在空位慢慢凝聚成型
4. **归位效果**："咔嗒"一声，书稳稳地立在书架上
5. **书名浮现**：书脊上的书名慢慢显现出来

整个动画持续3-5秒，配合轻柔的音效，让用户舍不得跳过。

---

### 借阅状态可视化

**被借出的书籍位置（空位占位框+标注）**：
```
┌────────┐
│  (空)  │
│        │
│ 📅 3天 │
│ 👤 小  │
│   法师 │
└────────┘
```

设计细节：
- 不是简单地"消失"，而是留下一个半透明的占位框
- 标注：借阅者头像/名字、归还倒计时
- 快到期时边框微微闪烁黄色
- 逾期时边框变红（但NPC不会真的逾期太久）

**归还动画**：
- 一本书从画面外"飞"回空位，"咔嗒"归位
- 旁边冒出一个小气泡："小魔法师还书啦！还附了一张便签..."

---

### 书籍5级升级系统及对应视觉效果

| 等级 | 抄写次数 | 视觉效果 |
|------|----------|----------|
| LV0 | 未解封 | 空位，灰蒙蒙的轮廓 |
| LV1 | 1次 | 普通纸质书，书脊单色 |
| LV2 | 3次 | 皮质封面，书脊有烫金 |
| LV3 | 7次 | 魔法装帧，书页会微微发光 |
| LV4 | 15次 | 古籍版本，书页泛黄，有金边 |
| LV5 | 30次 | 传说版本，悬浮在书架上，周围有魔法粒子 |

**升级时的仪式感**：
- 书架上的那本书开始"进化"动画
- 封面、书脊、光泽度逐步变化
- 弹出："《希腊神话故事》升级为传说版本！它开始散发金色光芒..."

## 三、书签页面与成果卡片系统

### 单本书签页面5级解锁内容设计

每抄完一本书，自动解锁这本书的专属书签页：

```
┌─────────────────────────────────┐
│     📖 《希腊神话故事》         │
│     ─────────────────           │
│                                 │
│    [ 书籍封面插画 ]             │
│                                 │
│   ✨ 已抄写：1次                 │
│   📅 首次完成：2026.05.13       │
│   👥 被借阅：3次                 │
│   📝 最受欢迎章节：特洛伊战争   │
│                                 │
│   ─────────────────────        │
│   "人类的愚蠢，连众神都无奈"    │
│          —— 书中摘录            │
│                                 │
│  [ 生成分享卡片 ]  [ 继续誊抄 ] │
└─────────────────────────────────┘
```

**随着誊抄升级，书签页面也会解锁更多内容**：
- LV1 解锁：基础信息（抄写次数、完成日期、借阅次数）
- LV2 解锁：书籍简介
- LV3 解锁：3句书中金句
- LV4 解锁：访客对这本书的评价
- LV5 解锁：书籍的"隐藏结局"或"作者秘闻"

### 温和社交系统设计

**核心原则**：不做排行榜，不做竞争，只做正向激励

#### 1. 串门系统
- 你可以去朋友的图书馆参观
- 看到TA的书架、收藏的书、接待过的访客
- 可以在TA的"访客留言簿"上留一句话（类似评论）
- 心理学：不是"TA比我厉害"，而是"哇，TA居然解锁了那本稀有的书！"

#### 2. 书籍漂流功能
- 你可以把自己誊抄过的书"复印一份"送给朋友
- 朋友收到后可以直接阅读这本书（无需从头抄）
- 但只有自己亲手抄完才能升级到LV2+
- 效果：互相激励，"我抄完这本书送你，你抄完那本送我"

#### 3. 联合修复活动
- 节日活动：全服用户一起抄书，达到目标解锁全服奖励
- 比如"全服累计抄写100万页，解锁限定书籍《龙族》"
- 每个人的努力都算数，但没有人因为"不够努力"被惩罚

## 四、图书馆日志系统（AI生成）

### 成本分析与可控性

#### 基础测算
| 维度 | 估算值 |
|------|--------|
| 每次调用字数 | 150-200字（一页日志） |
| 每次调用tokens | 约300-500 tokens |
| GPT-3.5-turbo成本 | 约0.001-0.002美元 / 次 |
| 1000日活用户每日成本 | 1-2美元 |
| 1000日活用户每月成本 | 30-60美元 |

#### 成本优化空间
1. **用更便宜的模型**：DeepSeek、Qwen等国产模型，成本可以降到1/5-1/10
2. **模板+变量**：70%内容用模板，30%用AI生成个性化内容
3. **缓存策略**：类似的操作组合复用相似的日志描述
4. **频率控制**：连续专注3次才生成一次日志，而不是每次都生成

---

### 精灵设定（墨墨）

- **名字**：墨墨（小墨精灵）
- **性格**：有点古板但温柔，喜欢看书，有点小啰嗦，偶尔会吐槽用户的专注习惯
- **声音**：像一个在图书馆工作了很多年的老管理员

---

#### 日志内容结构


#### 不同操作对应的日志内容
| 用户操作 | 日志描述示例 |
|----------|-------------|
| 完成一次25分钟专注 | "今天主人很认真，安安静静抄了25分钟，连羽毛笔掉在地上都没察觉..." |
| 中途放弃专注 | "主人写到一半被叫走了，墨墨把半干的书页小心收好了，等主人回来继续～" |
| 连续专注3次 | "今天真是高效的一天！书架上一下子多了三本新书，墨墨整理了好久呢..." |
| 一本书升级到LV2 | "《希腊神话故事》今天换上了皮封面，摸起来手感好多了，主人真棒！" |
| 有访客来借书 | "小魔法师冒冒失失闯进来，借走了《基础魔法》，希望他不要把书弄脏..." |
| 访客还书 | "小魔法师来还书了，还附了一张便签：'谢谢你的书，我学会第一个咒语啦！'" |
| 完成一个里程碑 | "书架修复度达到20%了！窗外的阳光似乎都比昨天更明亮了一些～" |

---

### 进阶玩法

#### 1. 日志收集系统
- 日志会积累成一本《图书馆日志》实体书
- 用户可以随时翻到历史某一天，回看自己当时的专注记录和发生的故事
- 每满30页，日志会"升级装帧"（从线装到皮装到魔法装帧）

#### 2. 精灵性格进化
- 随着用户使用时间变长，墨墨会"越来越了解你"
- 比如知道你喜欢早上专注，会写"主人果然还是早上最精神～"
- 知道你经常中途被叫走，会写"墨墨已经习惯帮主人收好书页了（摊手）"

#### 3. 隐藏彩蛋日志
- 某些特殊操作会触发特殊日志
- 比如连续7天不放弃专注："主人这周一次都没有中途离开，墨墨偷偷在你书架上放了一颗糖～"
