# 缮写室视觉化计划

> 目标：将专注/誊抄页面从「计时器 + 进度条」升级为具有沉浸感的缮写室场景，强化专注仪式感。

---

## 现状问题

1. **视觉单调**：当前页面以文字和进度条为主，缺少持续吸引注意力的视觉元素。
2. **专注反馈弱**：时间流逝和字数增长缺乏视觉化表达。
3. **场景感不足**：虽然有 focusroom 背景图，但与誊抄动作、书籍内容关联不强。

---

## 视觉化方向

### 一、核心视觉元素

1. **书写动画**
   - 羽毛笔 / 毛笔在羊皮卷上移动
   - 字迹逐行显现（可抽象为粒子或线条）
   - 动画速度与当前誊抄速度挂钩

2. **书籍封面展示**
   - 当前誊抄书籍的封面置于画面一侧
   - 随进度推进，封面周围出现微光 / 尘埃效果

3. **环境氛围层**
   - 蜡烛 / 油灯光影随时间微微摇曳
   - 窗外天色随真实时间变化（白天/黄昏/深夜）
   - 氛围阶段影响室内装饰细节

### 二、进度视觉化

- 已抄字数以「卷轴展开长度」或「墨水填充」形式呈现
- 章节解锁时播放小动画（如印章落下、书页翻开）
- 专注 streak 以连续点燃的蜡烛表示

### 三、交互细节

- 暂停时烛火变暗、动画缓停
- 完成时墨水瓶泛起金光，短暂庆祝动画
- 长时间专注后，画面角落出现墨墨飞过

---

## 技术要点

- 优先使用 CSS 动画 + 少量 Canvas/SVG，控制性能消耗
- 移动端简化效果，保证流畅
- 提供「低性能模式」开关，关闭复杂动画

---

## 实现步骤

1. 确定视觉风格参考（参考图 / moodboard）
2. 设计静态场景构图
3. 实现书写动画原型
4. 绑定动画与字数/时间进度
5. 增加章节解锁、完成等节点动画
6. 移动端适配与低性能模式

---

## 验收标准

- [ ] 专注过程中页面有持续、不刺眼的动态反馈
- [ ] 字数增长与视觉变化同步，误差 < 1 秒
- [ ] 移动端 60fps，低性能模式可关闭复杂效果
- [ ] 完成时有不打断流程的轻庆祝动画
