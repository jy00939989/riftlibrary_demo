# 书籍损毁意外事件扩展计划（book-damage-events）

> 现状：书籍损毁仅在访客归还时触发（~3% 基础概率），来源单一、叙事感弱。
> 目标：增加环境/灾难/意外类损毁来源，让“修缮室”和“爱惜书籍”标志牌更有存在感，同时不过度惩罚玩家。

---

## 一、新增损毁来源脑暴

### 1. 鼠患（🐭）
- **触发**：夜间 tick 或每日首次打开游戏时低概率触发。
- **影响**：随机啃坏 1 本已上架的“非典藏版”书籍，损失 5–10% 已抄字数。
- **叙事**：“昨夜有老鼠从窗缝钻进来，把《xxx》的书角啃成了月牙形。”
- **预防**：
  - 新增标志牌「猫馆长」：大幅降低鼠患概率。
  - 借阅区等级越高，鼠患概率越低（环境整洁）。
- **频率**：每月 0–1 次，前期略高、后期几乎为零。

### 2. 蛀虫（🐛）
- **触发**：针对长期未被借阅/翻阅的“冷门书”，每过一定天数概率累加。
- **影响**：缓慢侵蚀，首次触发只损失 1–3% 字数；若持续不管，可叠加到 15%。
- **叙事**：“书页间有细小的蛀洞，像谁用针尖戳了一片星空。”
- **预防/修复**：
  - 被访客借阅一次即可“通风”，重置蛀虫计时。
  - 标志牌「樟木书签」减缓蛀虫速度。
  - 修复时额外消耗少量灵感（驱虫）。

### 3. 火灾（🔥）
- **触发**：稀有灾难事件，与台风同级别的全馆灾难。
- **影响**：损坏 1–3 本非典藏版书籍（损失 20–30% 字数），并短暂降低氛围。
- **叙事**：“烛台倒了。等你赶到时，焦痕已经爬上了三本书的脊背。”
- **预防**：
  - 标志牌「防火标识」：大幅降低火灾概率。
  - 完成某访客任务后解锁“自动灭火沙罐”。
- **联动**：可触发紧急修复日常任务或全馆检查事件。

### 4. 台风波及书籍（🌪️）
- **触发**：现有台风事件目前只影响植物，扩展为“强台风”时可波及窗边书架。
- **影响**：若图书馆 atmosphere 阶段较低（建筑破旧），台风可能浸湿/吹落 0–2 本书，损失 10–20% 字数。
- **叙事**：“雨从窗框渗进来，泡皱了《xxx》的最后几页。”
- **预防**：
  - 图书馆 atmosphere 阶段越高（建筑越稳固），书籍越安全。
  - 标志牌「密封窗棂」专门针对台风/潮湿。

### 5. 潮湿霉斑（🌧️）
- **触发**：连续多日高湿度（可用随机或季节系统模拟，或简单用氛围阶段反推）。
- **影响**：随机 1–2 本书出现霉斑，损失 5–10% 字数；若不及时修复，霉斑扩散。
- **叙事**：“空气太潮了，书页边缘长出灰绿色的霉斑，像谁在书上画了一幅地图。”
- **预防**：
  - 标志牌「除湿炭包」。
  - 专注时长累计可触发“开窗通风”日常，降低潮湿概率。

### 6. 积灰（🌫️）
- **触发**：低烈度、高频但几乎无惩罚的事件。
- **影响**：书籍封面积灰，不损失字数，但降低该书被访客选中的概率；清洁后恢复。
- **叙事**：“《xxx》的书脊上落了一层薄灰，看来很久没人翻开它了。”
- **玩法**：可作为引导玩家使用“清洁”互动的 gentle nudge。

### 7. 墨水打翻（🖋️）
- **触发**：专注失败或放弃时极低概率触发。
- **影响**：当前正在誊抄的书损失少量已抄字数（3–5%）。
- **叙事**：“手肘碰翻了墨水瓶，墨迹在纸上洇开一朵黑色的花。”
- **设计意图**：把“专注放弃”的负反馈从纯数值变成一点叙事事件。

### 8. 窃书（🦹）
- **触发**：某些特定访客（如神秘商人、流浪诗人）归还时极低概率“忘了还”。
- **影响**：该书从书架消失（状态回到 unlocked 或 copying），不是损毁而是“丢失”。
- **叙事**：“那位访客离开时，怀里似乎藏着什么东西。你检查书架时，发现《xxx》不见了。”
- **回收**：可通过该访客再次到访时交涉、或完成其任务线追回。

## 二、机制设计原则

1. **典藏版（indestructible）始终免疫**：保持其尊贵感。
2. **修缮箱/修复中书籍免疫**：已在修复流程中的书不再二次受灾。
3. **惩罚有界**：单次损失不超过 30%，且可通过专注修复补回。
4. **预防大于治疗**：标志牌和升级应显著降低概率，让玩家感到投入有价值。
5. **叙事优先**：每个事件都配一句墨墨日志/历史记录，避免纯数值打击。
6. **可选开关**：可在设置中关闭“灾难事件”（保留归还损毁），照顾休闲玩家。

---

## 三、建议优先级

| 优先级 | 事件 | 理由 |
|---|---|---|
| P1 | 鼠患 | 实现简单、叙事可爱、与标志牌系统天然联动 |
| P1 | 潮湿霉斑 | 与现有 atmosphere/图书馆阶段系统联动，有成长曲线 |
| P2 | 火灾 | 高冲击灾难，需要 UI 弹窗和紧急事件支持 |
| P2 | 台风波及书籍 | 复用现有台风 tick，扩展成本低 |
| P3 | 蛀虫 | 需要“冷门书”计时逻辑，实现中等 |
| P3 | 墨水打翻 | 与专注系统联动，但惩罚感需轻 |
| P4 | 积灰 | 几乎零惩罚，可作为氛围/引导点缀 |
| P4 | 窃书 | 涉及访客任务线，设计复杂 |
