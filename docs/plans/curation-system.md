## 一、设计定位

**A+C 混合型**：开罗游戏式连携机制。玩家通过拖拽排列书架上的书籍位置，触发不同维度的"连携"组合，解锁数值加成和叙事彩蛋。排列本身是一种探索——隐藏配对需玩家自己试验发现。

**核心类比**：开罗游戏的建筑连携（特定建筑相邻触发 combo）。

---

## 二、连携维度（3种）

| 维度 | 来源 | 触发条件 | 判定范围 |
|------|------|----------|----------|
| **分类共鸣** | `category`（已有字段：哲学/小说/历史/科学/童话/诗歌/寓言） | ≥3本连续同category | 左右相邻连续 |
| **时代共鸣** | `era`（新增字段，见下方枚举） | ≥3本连续同era | 左右相邻连续 |
| **作者对话** | 精选配对表（新配置文件） | 2本配对在同排 | 同一排5格内任意位置 |

**注意**：不计算上下——只有左右相邻（1×5 的一维架子）。

## 四、连携层数阶梯

| 档位 | 条件 | 效果 | 视觉 |
|------|------|------|------|
| **3连·小成** | 3本连续同属性 | +1% 数值加成 | 细光效连线 |
| **4连·大成** | 4本连续同属性 | +1.5% 数值 + 墨墨点评 | 中光效连线 |
| **5连·圆满** | 5本满架同属性 | +2% 数值 + 称号/成就 + 叙事事件 | 亮光效连线 + 架端标记 |

### 数值分配规则
- **同 category 连线**：缮写速度加成（3连+1%，4连+1.5%，5连+2%）
- **同 era 连线**：访客停留时间/借阅率加成（对应档位）
- **作者配对**：专注结算智慧之光 +3%（同排触发，只有一档）
- **多层叠加**：如果同一位置同时触发 category + era 连携 → **效果叠加**（不取最高）
- 所有加成汇总到全局状态栏（馆长办公室下方），可点击展开详细数值

## 六、书架数据模型

```js
// 旧模型（仅计数）
state.library.shelves = [1]  // 每元素=一个书架，无位置信息

// 新模型（含位置）
state.library.shelves = [
  [null, 'book_001', 'book_016', null, null],  // 架子1：5个槽位
  ['book_006', 'book_011', null, null, null]     // 架子2
]
```

- 每个架子 = 长度为 5 的数组，null = 空位
- 拖拽交换 = 交换数组内两个位置的值
- 新书上架（手稿箱誊抄完成）= 放入当前书架最后一个空位
- 排序信息随存档持久化

## 七、UI 交互

| 要素 | 规格 |
|------|------|
| **拖拽模式** | 简单交换：拖A到B位置 → 交换 |
| **操作成本** | 随时免费拖拽 |
| **触发反馈** | 连携触发时弹出 toast + 架子上持续显示光效连线（两者都有） |
| **效果可见** | 书架上直接显示连携标识 + 馆长办公室状态栏汇总所有策展加成，点选可展开详细数值 |
| **配对发现** | 精选配对完全隐藏，需玩家自己试验排列来发现。不提供提示 |
