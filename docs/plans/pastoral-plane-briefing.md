## 0. 一句话（北极星）

**你是位面行者——不是挥剑的英雄，而是夹在两个世界之间的信使。**
你每抄一页书，山谷里就有一盏灯多亮一分；你每回一封信，某个人的命运就悄悄转弯。瘟疫不向你挥刀，它只是让邮箱安静几天——而那安静比任何怪物都吓人。

> 纪律：凡不能服务「信使的重量」的设计（街机小游戏、无限刷资源）都是反幻想的。

## 4. 三个分支点 + "痕" ✅

| 点 | 幕 | 抉择 | 旗标 | 病倒顺序影响 |
|---|---|---|---|---|
| **①** | 2 | 瘟疫 blame 落地后：公开护草药师 / 借教会之手 | `herbal_trusted` / `faith_trusted` / `p1_unanswered` | herbal→卡特琳先病；faith→玛格丽特先病 |
| **③** | 3 | 禁书处置：直接交给艾德里安 / 先经杜兰伯爵 | `adrian_open` / `adrian_cautious` / `p3_unanswered` | open→艾德里安幕4冒险暴露（病一场） |
| **②** | 4 | 向领主进言：直陈 / 迂回 | `lord_convinced` / `lord_shamed` / `p2_unanswered` | shamed→村庄幕5初仍封锁 |

**三态制**：每点 = 选项A / 选项B / `unanswered`（幕推进时未答自动落）→ **3 点 × 3 态 = 27 组合**。

**"痕"的三条载体（全部必做）**：
1. **即时闭环**：分支落定后 24-48h 游戏内收到该角色的旗标差异化短回信（每点 2 篇变体）
2. **病倒与离别**：损失模型 + 分区视觉态
3. **墨墨**：每幕至多一处**含蓄**引用（「我记得」对，「你把草药书递给了她」错）；引用**玩家**不枚举旗标；集中兑现于结局

## 5. 三结局 ✅（规则表机检）

判定输入 = `{p1, p2, p3}`。规则**有序**，首命中生效，**恰好一条 default**：

| # | 条件 | 结局 |
|---|---|---|
| R1 | p2=convinced ∧ p1≠unanswered ∧ p3≠unanswered | **曙光** 🌅 |
| R2 | p2=convinced ∧ p1=unanswered | 余烬（医者从未被信任——空心胜利） |
| R3 | p2=convinced ∧ p3=unanswered | 余烬（学者的线头未织完） |
| R4 | p2=shamed ∧ p1≠unanswered | 余烬（抵抗年代） |
| R5 | default | **长夜火种** 🌌 |

- 27 组合分布：**曙光 4 / 余烬 11 / 长夜 12**（totality 测试每行恰一结局）
- **D7 对称性**：herbal+convinced 与 faith+convinced 都能到曙光——两条幕2路线都有最好结局路径，差异落在结语/信物注记/分区终态
- **信物图鉴永不缺格**：condition 只影响获得时机/风味注记，未得显示「另一条时间线可得」

| 结局 | 演出 | 信物 | 熟客 |
|---|---|---|---|
| 曙光 🌅 | 山谷全复苏终图 + 双路线异结语 | 5 全得 | 五人全入池 |
| 余烬 🕯️ | 复苏 2/3 + **一名角色离别**（最后一封信+永久痕迹） | 全可得，时机异 | 五人全入池（离别者=流浪熟客） |
| 长夜火种 🌌 | 阴郁终图 + 图书馆窗光 | 全可得，时机异 | 五人全入池 |

## 6. 游戏机制（系统层）✅

### 6.1 损失模型（D8——"缺失即惩罚"）
**永不做页面死亡**，三个机制：
1. **病倒**：角色按旗标表病倒**真实游戏日**（按活跃游戏日 `onNewDay` 语义，离线不累计；同时病倒 ≤2 人）→ 信件暂停到达，**静默邮箱就是惩罚**；病倒可愈，痊愈信即补偿
2. **离别**：仅余烬结局一名角色永久离开（最后一封信 + 永久痕迹 + 选择前预告「这封信寄出后，有些门会关上」）
3. **解耦**：离开山谷者仍以「流浪熟客」来访图书馆——**损失在叙事层，不在数值层**

### 6.2 可插拔交互模块（八键接口）
```js
registerZoneModule('gather', {
  enter, interact, leave,
  render,            // 谷视图挂载
  onNewDay,          // 挂 day-boundary 总线，禁自带 Date 数学
  serialize, deserialize,
  canInteract,       // 分区自判灰锁
  allowedDuringFocus // gather=false；tend/vignette=true
})
```
位面#1 三模块：**gather**（会后收割）、**vignette**（聆听独白）、**tend**（教堂照料，onNewDay 日结一次、无离线补发）。

### 6.4 谷视图交互规格
- **竖版 3:4**（山谷纵深构图）；横屏左图右列表双栏
- **导航归宿**：谷视图 = act 门控的**第 9 个 tab「田园」**，幕<3 不渲染；幕3 开谷仪式性出现
- 热区 ≥48px 圆形按钮（360px 视口 ≥44px）；分区快捷列表为主交互
- **专注并发**：gather 专注中禁入（热点显示「专注结束后再来」——限制做成风味）

### 6.5 gather / tend（重复型产出，带 cap）
- **gather**：每专注会话一次、每日 ≤3 次、≤10💰/次。「艾拉替你采了一篮，因为你今天守住了专注」→ 结构上不可能比专注刷得更快
- **tend**：每登录日 1 次 ≤5💰，挂 `onNewDay`，离线不补发

### 6.6 存档与迁移
- 运行时键是 **`state.quests`**（不是 `state.planes`）——flags 落 `state.quests.<planeId>.flags[]`，**不改名**
- 迁移 **v13 → v14**：旧字段**只读不删**（现行 `plagueProgress` delete 是反例）；含 M1-M6 矩阵（fresh / 飞行中 / 已完成 / 损坏 / 幂等 / 旧字段深比较）

## 7. 经济联动（v3 §九——2026-09-18 新增）🔶
