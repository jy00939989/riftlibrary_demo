## 二、机制层

### P0-4　火灾罚金与新模型冲突：花光库存 = 免疫火灾

- 现状 `disasters.js:154`：`addAtmosphere(-Math.min(FIRE.atmospherePenalty, state.library.atmosphere || 0))` —— 罚金**不会扣成负数**。
- 于是：库存常年为 0 的玩家，火灾的氛围惩罚 **恒等于 0**。
- 新模型给了玩家"立刻把氛围花掉"的强动机（升设施 / 升阶仪式），**理性最优策略变成永远不留库存** → 火灾的氛围威慑被完全规避。
- 更糟的是它与"库存"概念本身冲突：**如果最优解是零库存，那"藏书厅库存"这个设计就没有意义**——玩家只在攒够仪式的那一瞬持有氛围。这直接削弱 §〇 体验目标 2 的"资源博弈"（博弈的前提是"持有"有价值）。
- **建议（三选一）**：
  1. 罚金**可透支到自由池**（先扣库存，不足部分扣自由池）——推荐，最简单且保住威慑；
  2. 罚金允许负值，下次进账自动抵扣；
  3. 火灾改罚**非氛围**维度（损书 / 停业 / 访客流失），彻底避开这个交互。

### P1-5　场馆维持费"恒大于日产" = 场馆变负资产（自毁设计）

- §五 闸 2：四房间维持费合计 **> +30/日**（满级设施日产），使自由池净流为负。
- 但房间是**自由池的消费口 / 玩法内容**（决策 10），玩家建房间是为了拿玩法收益（茶室羁绊 / 温室植物 / 庭院活动日 / 档案室馆史）。
- 若维持费 > 日产，则**建房间后自由池净流为负 → 房间是纯负债 → 理性玩家不建 → Phase 5 整期无人使用**。
- 这与"自由池出口"的设计意图**完全相反**：出口变成了惩罚。
- **修正**：维持费应 **< 房间带来的收益**，让房间值得建；它的作用是"**拉长**自由池净积累速率"，不是"转负"。
- 若采纳 P0-12（删除/改造设施日产），闸 2 的前提（+30/日）消失，此矛盾自然消解。

### P1-6　自由池软顶应升为主闸

- plan 把软顶列为"备选（闸 3）"，但它其实**最简单、最可控、且与藏书厅 500 顶同构**。
- 兑灵感日上限（闸 1）只限流**出口**，不改流入 → 自由池仍无限堆积，只是兑得慢（堆积本身仍是隐患，且 UI 上会显示一个越来越吓人的数字）。
- 维持费闸（闸 2）如上会毁掉场馆。
- **建议**：主闸 = **自由池软顶**（如 3000，超出不再增长或 10:1 折损）＋ 兑灵感日上限防灵感通胀；维持费回归"房间的使用成本"，不再充当通胀闸。

### P1-7　磨损用加性 → 高等级时相对惩罚更重

- `getDamageChance` 基准 = `max(0.5%, 3% - 0.4%/级)`：Lv1 = 3%，Lv7 = 0.6%，care 后 0.5%。
- 磨损 `+0.2%/次`，上限 `+3%`，**绝对值相加**：
  - Lv1：3% → 6%（磨损占比 50%）
  - Lv7：0.6% → 3.6%（磨损占比 **83%**）
- 即**借阅区越高级，磨损的相对惩罚越重**，稀释了"花大钱升借阅区降低损毁"的价值感——玩家会觉得"我升了级怎么还是这么容易坏"。
- **建议改乘性**：`×(1 + 0.6 × wearSteps/15)`（满磨损 ×1.6），各级相对影响一致，保住升级的价值感。
- 附带：care 标志牌在 Lv7 只把 0.6% → 0.5%（几乎无效）是既有问题，磨损叠加后会更明显，可顺带修。

### P1-8　磨损 → 重抄 → 灵感 sink 链条未被点明（其实是好事）

- 重抄花费 = **1 灵感**（`book-progress.js:171`）。磨损累积 → 玩家重抄 → 灵感回收。
- 这是全局**唯一成规模的灵感 sink**（另见 item-distribution 评审的 DLC 售卖）。**磨损速率直接决定灵感 sink 强度**。
- 建议在 §四 明确写出这条链，并纳入 Phase 0 测算：磨损速率 ↔ 重抄频率 ↔ 灵感消耗。

### P1-9　决策 6"占比随级爬升"无公式

- "低等级纯智慧之光（新手保护），高等级氛围成大头"没说**氛围占比如何随级变化**，无法落地。
- 建议给公式：`atmoRatio = clamp((lv - 2) / 4, 0, 0.8)`，或按等级查表。
- 并明确：**智慧之光与氛围不可兑换**——若可兑换，双消耗就退化成单消耗，"博弈"消失。

### P2-10　修复室老档补发是凭空造钱

- §六"补发 = Σ(各级 × 旧 15)"对借阅区/缮写室成立（`library-upgrades.js:28/72` 确有「+15氛围」）。
- 但**修复室升级文案是「修复速度 +5%」（`capacity.js:266`）**，另有修缮箱扩充(:218)、解锁(:242)也都**不含氛围** → 修复室整条轨道**从不给氛围**。
- 按 15/级 补发 = 凭空造钱。
- **修正**：补发按设施分别取**历史实发值**（借阅区/缮写室 15/级，修复室 0），或统一按"历史实发"重算。

## 三、数值层

### 3.1　供给侧实测（plan 缺失，Phase 0 无米之炊）

plan §三只有**成本侧**，没有**来源侧**——所有 [PLACEHOLDER] 都无从定值。实测 26 个 `addAtmosphere` 调用点，分类如下（**作为 Phase 0 参数表底稿**）：

| 类别 | 来源 | 实测值 | 频次 |
|---|---|---|---|
| 循环·**主导** | 还书 `returnAtmo`（visitors.js:1122） | 1/1/3/3/5/5/5（Lv1-7） | 受 `cap(2→10) × 周转率` 限制 |
| 循环 | 日常任务（dailytasks:31/51） | 1 / 3 | 日 |
| 循环 | 行动卡（actioncards:52/108/135） | 1 / 1 / 2 | 日 |
| 循环 | 访客事件（visitors:541/949/978/1017/1064） | 2 + `r.atmosphere` | 偶发 |
| 循环 | 植物收获（plants:169） | `harvestAtmosphere`（收窄后 10-15） | 数日 |
| 循环 | 委托/引导/里程碑/日记 | 1-3 | 不定 |
| 一次性 | **书籍完成**（book-progress:84） | `3/6/10` 按字数 ×(首抄 1 / 重抄 **0.5**) ×(单卷 0.5) | 68 本，**总量有限** |
| 一次性 | 设施升级（library-upgrades:27/71/88） | +15（新模型改为 等级×40~60） | — |
| 一次性 | 单卷/界域门/商店 | 10 / 10 / 5 | — |
| **负向** | **火灾**（disasters:154） | `-min(penalty, 当前持有)` | 见 P0-4 |

**关键结论**：还书是唯一高频循环来源，其产能 = `cap × 周转率 × returnAtmo`。借阅区 Lv1→Lv7 时 cap 2→10、returnAtmo 1→5，理论产能提升 **25 倍**——**这才是"设施 = 产能"的真正杠杆**，而不是 §三 写的"每级 +2/日"。

### 3.2　总账与周期（手估 [估算·待标定]，周转率按 1.5 次/日/位假设）

| 阶段 | 日均氛围（估） | 构成 |
|---|---|---|
| 前期 Lv1-2 | ~11/日 | cap2-3 × 1.5 × 1 + 任务/卡 ~8 |
| 中期 Lv4 | ~40/日 | cap7 × 1.5 × 3 + 任务 + 设施日产 |
| 后期 Lv7 | ~85/日 | cap10 × 1.5 × 5 + 设施日产 30 |

- 消耗侧：设施 6590（1630+3700+1260）＋ 仪式 834 = **7424**
- 90 天供给（估）：前期 330 ＋ 中期 1500 ＋ 后期 3450 ＋ 书籍一次性 ~500 ≈ **5780** → 超支约 22%，首通周期推到 **120-150 天**（旧模型 33 天撞 500 顶，约 4-5 倍）

> 拉长本就是你的诉求（"到星辰之境太快"），4-5 倍未必是坏事；但**周转率 1.5 是我猜的**，必须由 Phase 0 脚本用真实数据标定。

### P0-11　时序死锁：产能杠杆最贵，且前置

- 借阅区是**唯一真正的产能杠杆**（25 倍），却也是最贵的一项：**3700，占设施总成本 56%**。
- 前期日均仅 ~11，而借阅区第一档氛围成本就 100（Lv3）→ 需 9 天纯攒；Lv4 要 250 → 再 12 天。
- 玩家在**最缺产能的时候被迫购买最贵的产能** → 前期卡顿，且"资源博弈"在前期根本没有博弈空间（只有一条路：攒借阅区）。
- **建议：把借阅区氛围成本后置**——Lv3-4 压到很低甚至纯币（强化决策 6 的"新手保护"），成本集中到 Lv5-7（此时玩家已有产能，付得起）：
  - 现案：100 / 250 / 550 / 1000 / 1800
  - 建议：**0 / 80 / 300 / 700 / 1500**（Lv3-7）

### P0-12　核心建议：设施"每日产出"是冗余的第二套产能，建议改造或删除

plan 同时建了**两套产能**：

1. 借阅区等级 → cap / returnAtmo（**25 倍杠杆，真实主导**）
2. 设施每日产出 **+2/级/日**（满级 +30/日，**小头**）

第二套产能的**代价却很大**：

| 代价 | 说明 |
|---|---|
| 连锁问题 | 制造躺平风险（§八自认）→ 逼出闸 2 维持费 → 闸 2 又让场馆变负资产（P1-5） |
| 复杂度 | 需每日结算 + 离线补算（24h 上限）+ 迁移起算日，Phase 2 一整块工作量 |
| 收益有限 | 满级 30/日 相对后期还书 85/日 仅 35%，对"固定资产=产能"的体感贡献有限 |

- 违反"能用一套参数解释的，不用三套系统"。
- **建议（推荐）**：**删除氛围日产，改为每日产出非氛围资源**（如修缮材料 / 灵感碎片）。这样：保留"设施每天在为我干活"的养成体感，但不与氛围经济纠缠、不制造躺平、闸 2 自然消失、Phase 2 简化。
- **若坚持保留氛围日产**：必须大幅下调（如每级 +1/日，满级 +15/日），并明确其在总供给中的占比上限（建议 ≤20%）。
