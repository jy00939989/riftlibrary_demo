# 待补 sink 台账（sink-ledger）

> 建立：2026-09-10，借阅深化 × 咖啡角联合评审 D12（reviews/borrow-cafe-joint-review-v2.md）；v1.1 修订同日按经济子系统架构评审 A2/A4（economy-subsystem-architecture-review.md）。
> 目的：归口三份 plan 都记「系统级、不归我背锅」的资源缺口——每条线记 faucet 增速、现有 sink、责任计划、回调信号，杜绝散记。
> 规则：**新 plan 凡新增 faucet 必先在此登记**；观测指标超阈值时在本表补「处置记录」。
> **观测性质（A2 明示）**：金币线为数值阈值、可代码断言；灵感/好感/专注三线均为**人工巡检判据，非自动断言**——台账是月度人工复核流程，不是自动化监控。
> **基线声明（A2 必改）**：金币线「1.85×」基线来自 v4 仿真，**未建模 borrow 营收/寄读/咖啡角**，是本三件套上线前的旧值；上线后须用真实首月数据**重基线**，期间阈值仅作方向参考。扩仿真（专注脊柱 2.5 会话/日 + 三个新 faucet 入 `simulate-atmosphere-economy.mjs`）已立排期项（A2 方案一，长期受益）。

## 五、登记规则

1. 新 plan 凡新增 faucet（任一线，含专注线的「专注消耗」）→ 先在本文登记增速与 sink 假设。
2. 评审发现「不归我」的 sink 缺口 → 统一记到本文，禁止散记在各 plan 里。
3. 观测指标超阈值 → 在对应行「处置记录」补日期与处置，并回链触发 plan 的修订记录。
4. **仿真排期项（A2 方案一）**：扩展 `simulate-atmosphere-economy.mjs`——加「专注会话/日」脊柱输入（默认 2.5，可标定），建模 borrow 营收（含 ×0.25 额外书）、寄读（浮动上限）、咖啡角（维持费/休眠）；落地后 v4 的 173/207/254 天与金币基线在同模型重算，本文金币线自动转为可信账本。
