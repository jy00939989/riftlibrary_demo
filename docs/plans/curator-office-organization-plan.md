# 馆长办公室整理计划

> 目标：重新梳理馆长办公室（Office / 概览页）的信息架构与交互，使其从「数据堆砌」升级为「决策仪表盘」。

---

## 现状问题

1. **信息密度过高**：当前概览页同时展示氛围、资源、访客、任务、成就等多类数据，新手容易迷失。
2. **缺少行动引导**：玩家进入办公室后，不知道下一步该做什么。
3. **视觉层级混乱**：关键数据（如氛围阶段、今日馆务）不够突出，次要信息（如历史记录）占据过多空间。
4. **缺乏「馆长感」**：办公室作为游戏核心场景，目前更像统计面板，缺少归属感与仪式感。

---

## 整理方向

### 一、信息分层

| 层级 | 内容 | 展示方式 |
|---|---|---|
| 核心指标 | 氛围、智慧之光、灵感、连续专注天数 | 顶部 KPI 卡片 |
| 今日行动 | 馆务任务、待还书、待浇水、访客到期 | 中间待办清单 |
| 长期进度 | 成就、收集、位面任务、里程碑 | 下方折叠面板 |
| 辅助信息 | 历史记录、设置入口 | 抽屉 / 设置页 |

### 二、交互优化

- 点击 KPI 卡片可跳转对应页面（氛围→图书馆、智慧之光→商店等）。
- 今日行动未完成的项置顶，已完成的自动折叠。
- 增加「今日推荐」模块：根据当前状态推荐一个最优行动（如「先还书」「浇水」「开始专注」）。

### 三、视觉包装

- 为办公室增加背景图与光照变化（随氛围阶段切换）。
- 关键数字使用大字号 + 微动画。
- 增加馆长书桌、墨墨栖息处等小细节，强化场景感。

---

## 实现步骤

1. 梳理当前 `js/render/office.js` 或概览页渲染逻辑。
2. 重新划分信息区块，输出新版线框。
3. 实现 KPI 卡片与待办清单组件。
4. 增加「今日推荐」逻辑。
5. 迭代视觉包装（背景、动效、细节）。
6. 移动端适配测试。

---

## 验收标准

- [ ] 新手玩家进入办公室后 3 秒内知道下一步该做什么
- [ ] 关键数据一眼可见，次要信息不干扰
- [ ] 移动端各模块不溢出、不堆叠混乱
- [ ] 氛围阶段变化时办公室视觉有反馈
