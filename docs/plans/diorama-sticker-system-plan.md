# 造景贴纸系统开发计划

> 目标：开发一套「造景贴纸」系统，让玩家可以用解锁的贴纸装饰图书馆、缮写室、书架等场景，增加长期收集与表达动力。

---

## 核心概念

「造景贴纸」是一种轻量级装饰物：

- 玩家通过游戏进程解锁（成就、访客、活动、购买等）
- 可拖拽放置到预设场景网格中
- 不影响核心数值，只改变视觉
- 部分贴纸带有轻微动画或互动反馈

---

## 系统组成

### 一、贴纸资源

| 类型 | 示例 | 解锁方式 |
|---|---|---|
| 植物盆栽 | 蕨类、多肉、 Starlight Fern | 植物系统 / 种子兑换 |
| 家具摆件 | 烛台、地球仪、墨水瓶 | 成就 / 商店 |
| 访客纪念品 | 沈明远的批注卡、王小磊的徽章 | 访客事件 |
| 季节限定 | 中秋灯笼、圣诞花环 | 限时活动 |
| 联动贴纸 | 灰烬学院标志、四普档案章 | 跨项目联动 |

### 二、场景画布

1. **图书馆大厅**：书架之间的空地、阅读区墙面
2. **缮写室**：书桌、窗台、横梁
3. **馆长办公室**：书桌、墙面、角落
4. **书架特写**：单格书架内的装饰

每个场景提供固定数量的「锚点」或网格，贴纸只能放在锚点上，避免布局混乱。

### 三、编辑模式

- 点击「布置」进入编辑状态
- 底部弹出贴纸抽屉，按分类筛选
- 拖拽贴纸到锚点，可旋转 / 缩放（有限范围）
- 长按删除或收回抽屉
- 提供「恢复默认」和「保存布局」

### 四、数据持久化

```js
state.decorations = {
  library: [{ stickerId: 'potted_fern', anchorId: 'lib-window-left', rotation: 0, scale: 1 }],
  scriptorium: [...],
  office: [...]
};
```

## 实现步骤

1. 设计贴纸资源规范（尺寸、格式、锚点适配）
2. 实现 `data/stickers.js` 贴纸定义表
3. 实现贴纸解锁逻辑（与成就、访客、商店系统对接）
4. 实现场景画布与锚点系统
5. 实现编辑模式 UI（抽屉、拖拽、保存）
6. 实现装饰状态持久化
7. 性能优化：贴纸合批、懒加载

---

## 验收标准

- [ ] 至少 20 张贴纸可解锁
- [ ] 3 个场景可布置
- [ ] 编辑模式下拖拽流畅，放置有吸附反馈
- [ ] 布局保存后刷新不丢失
- [ ] 移动端双指缩放/单指拖拽不冲突
