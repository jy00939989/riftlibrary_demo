# 收藏系统优化计划（collection-system-optimization）

> 现状：`js/collection.js` 已实现书籍、里程碑、访客记忆、位面归档四类收集进度，但展示层较单薄，收集反馈弱，缺少“完成感”和“炫耀感”。
> 目标：让收藏系统成为玩家长期目标的可视化仪表盘，每次解锁都有明确反馈，满收集有仪式收尾。

---

## 一、当前问题诊断

1. **入口深**：收藏页藏在馆史档案或书架页，玩家不常点开。
2. **反馈弱**：解锁新收藏时只有底部 toast，缺少弹窗/动画/成就联动。
3. **分类杂**：四类进度混在一起，书籍类目下只有简单列表。
4. **无详情**：点击单本书/里程碑看不到解锁故事或额外 Lore。
5. **缺少阶段奖励**：收集度 25%/50%/75%/100% 时没有梯度奖励。
6. **典藏版存在感低**：`collectorCover` 只是 emoji，没有专属展示位。

---

## 二、优化方向

### 1. 独立收藏馆页面
- 在顶部导航增加「收藏馆」标签（🏛️ 或 🏆）。
- 页面结构：
  - 顶部：总完成度环形图 + 最近解锁
  - 中部：四类收藏卡片（书籍 / 里程碑 / 访客记忆 / 位面归档）
  - 底部：全收集奖励预览

### 2. 解锁反馈升级
- **首次解锁弹窗**：小卡片动画 + 墨墨一句评论。
- **阶段达成弹窗**：25%/50%/75% 时弹出“收藏馆升级”提示，给少量灵感/氛围奖励。
- **100% 全收集**：专属证书/称号/馆长办公室装饰（如墙上的星图）。

### 3. 书籍收藏细分
- 按位面、时代、分类、是否典藏版分组展示。
- 每本书显示：
  - 封面图（若已配置 `cover`）
  - 完成状态（未解锁 / 已解锁 / 已精通）
  - 熟练度等级（Lv1–Lv5）
  - 点击展开：简介、作者、解锁故事

### 4. 里程碑可视化
- 把 currently hidden 的里程碑变成可浏览的“图书馆年鉴”。
- 每个里程碑配小图标和达成时间。

### 5. 访客记忆墙
- 用关系网/卡片墙展示已遇见访客。
- 显示每位访客：
  - 到访次数
  - 最高好感度
  - 已触发叙事事件
  - 专属纪念物（若有）

### 6. 位面归档地图
- 把位面解锁进度做成“位面星图”。
- 已解锁位面点亮，未解锁位面灰显并提示解锁条件。

### 7. 典藏版专属展台
- 在收藏馆中为典藏版书籍设置独立展台。
- 展示 `collectorCover` 放大图或专属封面。
- 可点击聆听/阅读典藏版 `certMessage`。

### 8. 收集奖励梯度
| 完成度 | 奖励建议 |
|---|---|
| 25% | +1 灵感，解锁「初级策展人」称号 |
| 50% | +3 灵感，解锁收藏馆背景皮肤 |
| 75% | +5 灵感，解锁墨墨限定日志 |
| 100% | +10 灵感，解锁馆长办公室终极装饰 + 通关感文案 |

---

## 三、建议实施顺序

1. **Phase 1（快赢）**：
   - 增加「收藏馆」导航入口。
   - 书籍收藏页显示封面图 + 熟练度。
   - 解锁时加弹窗反馈。
2. **Phase 2**：
   - 实现访客记忆墙和位面星图。
   - 加入 25%/50%/75% 阶段奖励。
3. **Phase 3**：
   - 典藏版专属展台。
   - 100% 全收集仪式收尾。
