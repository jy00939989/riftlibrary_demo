# 展览厅计划（exhibition-hall-plan）v1

> 立项：2026-09-11。**图南三决策（立项前锁定）**：
> ① 展览厅承担原庭院功能——**开展限时活动**（现实日历活动日框架迁入）；
> ② **从一开始视觉化**——不是标签页，是一张展览厅大图上的一个个房间入口；房间初始黯淡破败，修复后变为可开放；
> ③ 解锁节奏**综合**（阶段+收集双轨），注重趣味性与逻辑链。
> **明确不做（留坑后续 plan）**：玩法动词（策展/布展等）、sink 具体形态（台账已记账：灵感持续消耗口责任归本厅）、活动奖励深度。
> 上游：氛围系统重设计 v4.3 Phase 4 场馆房间（房间定版 2026-09-10）；`atmosphere-venue-map-design.md` §D 活动遗产（已吸收案，本 plan 继承其活动日框架）。

## 一、定位与范围

**一句话**：全馆收藏品的「家」+ 限时活动举办地。前两个房间（咖啡角=交易、温室=生产）解决经济循环，展览厅解决**成就感陈列**与**现实仪式感**。

| 做（本 plan） | 不做（后续） |
|---|---|
| 展览厅大厅视觉化 + 五房间入口 | 策展/布展玩法动词 |
| 房间三态状态机（破败→修复→开放） | 金币/灵感 sink 具体形态 |
| 五功能迁入（档案/收藏/纪念牌/成就柜/留声阁） | 活动奖励数值深化 |
| 限时活动日历框架（静态表 + 触发） | 庭院（已否决，功能由本厅继承） |
| 房间解锁（综合轨） | 展览厅维持费/休眠（等 sink 批次一起定） |

## 二、空间视觉化（决策②）

### 2.1 大厅底图（美术债 1 张）
- AI 出图一张**展览厅全景**：大厅视角，五个门口/壁龛各对应一房间（档案室=卷宗门、收藏品=玻璃展柜、纪念牌=荣誉墙、成就柜=阶梯展台、留声阁=侧厅门），风格锚定 parchment/wood/琥珀金（同动画色调规范）。
- 入口即门/龛位上的**铭牌**（房间名 i18n），点击进房间子页。

### 2.2 房间三态（零美术债实现）
| 态 | 视觉 | 交互 |
|---|---|---|
| 破败 | 入口区域**灰度+暗化**（CSS filter: grayscale+brightness+锁标记 🔒） | 悬停显示修复条件；点击弹修复面板 |
| 修复中 | 灰度保留 + 微光进度 | —（本版不设施工时长，修复即完成，态仅两档） |
| 开放 | 全彩 + 铭牌发光 | 点击进入房间 |

> 修复的「蜕变」仪式感：修复点击后播一个**局部过渡**（CSS 光扫过入口区域 + 灰度褪去，~1.2s），呼应决策②的「从黯淡破败变成可开放」。动画清单的 `resto_*` 键系为修复室服务，本厅不入 seedance 清单（CSS 足矣，评审若认为值得再立项）。

### 2.3 导航结构
- 顶栏/导航新增「展览厅」入口（房间定版第三批）；大厅图 = 展览厅首页；五房间 = 子页（复用现有 render 页面，迁址不改内脏）。

## 三、房间清单与解锁（决策③：综合轨 + 逻辑链）

**总解锁公式**：`展览厅本体`（阶段轨）→ 各房间（收集轨，条件=「你已经拥有它要陈列的东西」——逻辑链：陈列什么，就先要拥有什么）。

| 房间 | 迁入来源 | 修复条件（收集轨） | 逻辑链说明 |
|---|---|---|---|
| 🏛 大厅本体 | 新建 | 3 阶 + 💰2000（对齐咖啡角 2 阶定价梯度） | 阶段轨；大厅开=展览厅玩法开门 |
| 📜 档案室 | 馆史档案页（archive） | 大厅建成即开放 | 档案是「馆的记忆」，随馆而生 |
| 🏆 成就柜 | 成就页 | **成就 ≥10 个** | 柜里要有东西才配开柜 |
| 🪧 纪念牌墙 | 标志牌收集（signboards） | **拥有 ≥1 纪念牌** | 同上 |
| 🎁 收藏品展柜 | collection.js 收藏页 | **任意收藏品 ≥5 件** | 展柜空置不开张 |
| 🎵 留声阁 | 音乐系统（已存在 upgrade） | 已建留声阁则入口直接点亮；未建显示「去商店建造」引导 | 已有系统迁入，不重复收费 |

> 趣味性补充：每房间修复时墨墨日志写一句「展厅巡查」叙事（房间专属一句，5 条文本）；全部房间开放时弹一次「展览厅全馆开放」全屏小庆典（复用 witness toast 模式）。

## 四、限时活动框架（决策①，继承 venue-map §D）

### 4.1 静态日历表（`data/event_calendar.js` 单一真源）
```js
// { id, month, day, nameKey, type: 'author'|'festival', roomHint, effect }
{ id: 'world_book_day', month: 4, day: 23, nameKey: 'evtWorldBookDay', type: 'festival',
  effect: { borrowFavorMult: 1.5 } }
```
- **判定**：`isEventDay(date)` 读系统日期匹配静态表（无调度框架依赖，页面加载/日界 tick 两处调用）。
- **首批锚点（图南待定稿，我先占位 8 个）**：4/23 世界读书日、4/2 国际儿童图书日、5/4 青年节（五四文学）、6/6 普希金诞辰、7/30 黑塞诞辰、9/11？、10/16 钱钟书诞辰、11/7 托尔斯泰诞辰、12/21 斯大林格勒？（占位需图南圈定—— podcast 讲过的英美文学作家优先）。
- **活动日表现（轻量，本 plan 范围内）**：展览厅大厅入口挂活动横幅 + 当日全局小增益（如借书好感×1.5 / 专注金币+10%）+ 墨墨日记提一句。**奖励深度/sink 化留后续 plan**。

### 4.2 不挂星象（沿用旧案约束）
现实日历锚点即可，不做游戏内虚拟历法。

## 五、迁入方案（纯加法）

- `js/render/archive.js` / `collection.js` 等页面逻辑不动，导航入口改指向展览厅子页；旧入口保留一个版本（兼容 muscle memory）后收编。
- 新增 `state.exhibition = { built: false, rooms: { archive: 'open', achievements: 'ruined', signboards: 'ruined', collection: 'ruined' }, lastEventId: null }`；迁移纯加法（A5 同档纪律，借 v10 或并入下一个迁移版本）。
- 大厅底图 `visual/exhibition/hall_v1.jpg`（美术债清单见 §七步骤 0）。

## 六、验收标准

1. 大厅图五入口可见，三态视觉区分明显（灰度破败 vs 全彩开放）。
2. 修复条件不满足时入口显示条件清单（复用设施门槛 UI 惯例）。
3. 五房间迁入后原有功能零回归（archive/collection/signboards/music 四页行为不变）。
4. 活动日判定：改系统日期测试，活动日横幅+增益生效，非活动日无残留。
5. 老档迁移：无 exhibition 字段时默认全破败（大厅未建）。
6. check:imports 过；零氛围违规（本 plan 不加任何氛围产出点）。

## 八、失败信号（预留，数值后续批次再定阈值）

| 信号 | 判据（暂定） | 含义 |
|---|---|---|
| A 大厅空置 | 上线一月展览厅页访问占比 < 5% | 入口太深或陈列无吸引力 → 玩法批次提前 |
| B 活动无感 | 活动日留存与非活动日无差异 | 增益太弱 → 数值批次加强 |
| C 迁入破坏 | 任一迁入页功能 regression | 迁入方案回滚 |
