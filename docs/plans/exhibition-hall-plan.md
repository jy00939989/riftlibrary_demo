## 一、定位与范围

**一句话**：全馆收藏品的「家」+ 限时活动举办地。前两个房间（咖啡角=交易、温室=生产）解决经济循环，展览厅解决**成就感陈列**与**现实仪式感**。

| 做（本 plan） | 不做（后续） |
|---|---|
| 展览厅大厅视觉化 + 五房间入口 | 策展/布展玩法动词 |
| 房间三态状态机（破败→修复→开放） | 金币/灵感 sink 具体形态 |
| 五功能迁入（档案/收藏/纪念牌/成就柜/留声阁） | 活动奖励数值深化 |
| 限时活动日历框架（静态表 + 触发） | 庭院（已否决，功能由本厅继承） |
| 房间解锁（综合轨） | 展览厅维持费/休眠（等 sink 批次一起定） |

## 二、空间视觉化（决策②）

### 2.1 大厅底图（美术债 1 张）
- AI 出图一张**展览厅全景**：大厅视角，五个门口/壁龛各对应一房间（档案室=卷宗门、收藏品=玻璃展柜、纪念牌=荣誉墙、成就柜=阶梯展台、留声阁=侧厅门），风格锚定 parchment/wood/琥珀金（同动画色调规范）。
- 入口即门/龛位上的**铭牌**（房间名 i18n），点击进房间子页。

### 2.2 房间三态（零美术债实现）
| 态 | 视觉 | 交互 |
|---|---|---|
| 破败 | 入口区域**灰度+暗化**（CSS filter: grayscale+brightness+锁标记 🔒） | 悬停显示修复条件；点击弹修复面板 |
| 修复中 | 灰度保留 + 微光进度 | —（本版不设施工时长，修复即完成，态仅两档） |
| 开放 | 全彩 + 铭牌发光 | 点击进入房间 |

> 修复的「蜕变」仪式感：修复点击后播一个**局部过渡**（CSS 光扫过入口区域 + 灰度褪去，~1.2s），呼应决策②的「从黯淡破败变成可开放」。动画清单的 `resto_*` 键系为修复室服务，本厅不入 seedance 清单（CSS 足矣，评审若认为值得再立项）。

**三态交互（grill #5 确认）**：破败态点击弹「修复面板」（房间名 + 修复价 + 收集条件清单未满足项打 ❌ + 修复按钮条件/金币不足置灰）；悬停/长按显示迷你条件提示。开放态入口常态显示，大厅页脚挂活动横幅位（书香月整月展示见 §4）。

### 2.3 导航结构（grill #1 定案：路线 A）
- 顶栏/导航新增「展览厅」入口（房间定版第三批）；大厅图 = 展览厅首页（热点导航门面）。
- **房间 = 现有整页复用**：点入口 → `switchTab` 到对应现有页，顶栏 tab 同步高亮；五页内脏一行不改。
- 工程注记：热点用底图百分比坐标（响应式自适应，移动端等比缩放可点）；房间页 header 加一行「🏛 展览厅 · X 室」面包屑回大厅。
- 迁入成本坍缩为：大厅页新建 + 导航重挂 + 五处入口状态点亮逻辑。

## 三、房间清单与解锁（决策③：综合轨 + 逻辑链）

**总解锁公式**：`展览厅本体`（阶段轨）→ 各房间（收集轨，条件=「你已经拥有它要陈列的东西」——逻辑链：陈列什么，就先要拥有什么）。

**大厅 = 分级设施（grill #4 图南拍板修订）**：不是一锤子建造——0→Lv1 便宜起步先建出来，**大厅等级 = 房间容量**（Lv1=1 间房，每升 1 级 +1 槽位，Lv5=5 间全开放），要往上修大厅才能修里面的房间。设施帽复用 getFacilityLevelCap（跟阶段走）。

| 项 | 阶段轨 | 金币轨 | 容量 |
|---|---|---|---|
| 🏛 大厅 0→Lv1 | 2 阶 | 💰800（便宜起步，先把大厅立起来） | 1 间房 |
| 大厅升级 Lv→N | 设施帽 stage+1 | 1000/1600/2560/4096（×1.6 曲线） | 每级 +1 槽 |
| 大厅绝对满级 | — | — | Lv5（5 槽） |

| 房间 | 槽位消耗 | 修复条件（收集轨） | 修复价 | 逻辑链说明 |
|---|---|---|---|---|
| 📜 档案室 | 1 | 大厅建成即开放 | **免费** | 档案是「馆的记忆」，随馆而生 |
| 🪧 纪念牌墙 | 1 | **拥有 ≥1 纪念牌** | 💰500 | 第一个收集品最易有，低价即时满足 |
| 🏆 成就柜 | 1 | **成就 ≥10 个** | 💰800 | 柜里要有东西才配开柜 |
| 🎁 收藏品展柜 | 1 | **任意收藏品 ≥5 件** | 💰800 | 展柜空置不开张 |
| 🎵 留声阁 | 1 | 已建留声阁则直接点亮；未建显示「去商店建造」引导 | 入口不收费 | 已有系统迁入，防重复收费 |

> 修复 = **金币 + 收集条件双门槛**（grill #4 定）：免费修会让「修复」变成白嫖点击，500-800 让修复是个决定；且这是展览厅 v1 唯一的金币回收点（维持费留坑 sink 批次）。

> 趣味性补充：每房间修复时墨墨日志写一句「展厅巡查」叙事（房间专属一句，5 条文本）；全部房间开放时弹一次「展览厅全馆开放」全屏小庆典（复用 witness toast 模式）。

## 四、限时活动框架（决策①，继承 venue-map §D）

### 4.1 静态日历表（`data/event_calendar.js` 单一真源）
```js
// { id, month, day, nameKey, type: 'author'|'festival', roomHint, effect }
{ id: 'world_book_day', month: 4, day: 23, nameKey: 'evtWorldBookDay', type: 'festival',
  effect: { borrowFavorMult: 1.5 } }
```
- **判定**：`isEventDay(date)` 读系统日期匹配静态表（无调度框架依赖，页面加载/日界 tick 两处调用）。
- **首批锚点（2026-09-11 图南圈定 + 克克补位）**：
  - **4/23 世界读书日 × 书香苏州**（「百步芳草 四季书香」苏州市全民阅读系列活动同日启动，图南苏州人指定收录）
  - 1/3 托尔金诞辰、9/25 鲁迅诞辰、9/15 阿加莎·克里斯蒂诞辰（波洛之父）、12/16 简·奥斯汀诞辰（图南指定四位）
  - 克克补位：4/2 国际儿童图书日、10/16 钱钟书诞辰（待定稿，图南可删改）
  - **书香苏州形态（grill #3 图南拍板 C）**：4 月整月挂「书香苏州」横幅（纯展示，monthSpan 区间仅用于展示层）+ 4/23 当天与「世界读书日」合并峰值 `focusCoinsMult: 1.2`（增益判定保持单日等值，不引入区间逻辑进数值层）。
- **活动日表现（轻量，本 plan 范围内）**：展览厅大厅入口挂活动横幅 + 当日全局小增益 + 墨墨日记提一句。**奖励深度/sink 化留后续 plan**。
- **增益双 hook（grill #2 图南拍板）**：🎂 作家诞辰 = `borrowFavorMult: 1.5`（书与人的链接）；🎊 节日（读书日/书香苏州/儿童图书日）= `focusCoinsMult: 1.1`（全民阅读普惠）。数值均为乘区当日生效、零永久遗留；**氛围口子不开**（EXP 总闸纪律，数值批次整体评估）。

### 4.3 活动演化路线（图南 2026-09-11 拍板方向，后续批次，本 plan 只留接口位）
1. **作者诞辰联动**：限时上架该作者书籍（DLC 式限时购买位）；
2. **全服合抄**：限时全员协力抄一本书，达成即入库——**架构注记**：需服务端聚合进度（Supabase 已有后端，新增一张 event_progress 表即可，前端读聚合值写个人贡献）；
3. **限时独占内容**：音乐 / 纪念牌 / 装饰（calendar 表已留 `id` 位，奖励结构后续扩 `reward` 字段）。
> 本 plan 的 `data/event_calendar.js` 结构按「id 可扩展 reward」预留，不写死 effect-only。
> **奖励边界（grill #5 确认）**：本批次活动日 = 横幅 + 当日增益 + 墨墨日记一句，零物品/货币直发；限时书/全服合抄/独占内容全在 §4.3 演化路线。

### 4.2 不挂星象（沿用旧案约束）
现实日历锚点即可，不做游戏内虚拟历法。

## 五、迁入方案（纯加法）

- 五功能散居现状（路线 A 前提）：馆史档案页=4 子标签（馆史/日记/访客记忆/位面）、纪念牌=馆内装饰页一区、收藏品/成就=独立整页、留声阁=独立页。迁入 = 大厅热点链接到这些现成页 + 入口状态由 exhibition.rooms 驱动；**不改任何页内脏**。
- 旧顶栏入口保留一个版本（兼容肌肉记忆），展览厅页脚给「旧入口即将收编」提示——**下个版本撤（已记 _todo-index 待办）**。

## 六、验收标准

1. 大厅图五入口可见，三态视觉区分明显（灰度破败 vs 全彩开放）。
2. 修复条件不满足时入口显示条件清单（复用设施门槛 UI 惯例）。
3. 五房间迁入后原有功能零回归（archive/collection/signboards/music 四页行为不变）。
4. 活动日判定：改系统日期测试，活动日横幅+增益生效，非活动日无残留。
5. 老档迁移：无 exhibition 字段时默认全破败（大厅未建）。
6. check:imports 过；零氛围违规（本 plan 不加任何氛围产出点）。
7. 五房间全开放时触发一次「全馆开放」庆典（一次性，不阻塞）；旧入口收编提示可见。
