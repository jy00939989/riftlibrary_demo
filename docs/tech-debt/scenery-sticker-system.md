# 造景贴纸系统：从温室页撤下的占位功能

> 类型：设计债 + 美术债
> 记录日期：2026-09-21（温室独立成页时撤下，图南决策「先去掉，记作技术债」）
> 状态：待立项 / 待美术资源

---

## 原始构想

温室（原「馆内布置」子标签）底部有一个「造景贴纸」占位区：

> 将盆栽和标志牌拖放布置到图书馆场景中

即：玩家把已拥有的植物/标志牌以贴纸形式自由摆放到底图（缮写室、读者沙龙等场景）上，形成个性化馆内布置。

## 2026-09-21 撤下原因

1. **只有占位没有实现**：占位卡挂了两个月，既没有交互也没有美术，纯视觉噪音
2. **温室独立成页后定位变化**：温室页聚焦「种植-培育-收获-兑换」循环（培育设施线），造景属于「展示/装扮」维度，混在一起稀释主线
3. **前置依赖重**：像样的造景需要场景底图的可布置区域定义 + 拖拽交互 + 位置持久化 + 一批贴纸级美术，不是顺手能做的体量

## 重做时要回答的问题

1. **载体**：摆在现有场景底图上（需要每张底图划可布置区），还是独立「我的书房」小场景（自由度最高、美术成本最低）？
2. **与收藏的关系**：是已获得盆栽/标志牌的「展示出口」，还是独立贴纸图鉴（新收集线）？
3. **数值挂钩吗**：纯展示，还是摆放位置影响访客事件/氛围（图南 2026-09-08 定调 EXP 模型后，装饰类收益要格外克制）？
4. **移动端交互**：拖拽在触屏上的手感（缩放/吸附/撤销）——2026-06-04 日记有过移动端盲区教训
