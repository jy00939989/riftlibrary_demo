# 植物系统：后期动力缺失 + 缺少废弃按钮

> 类型：设计债 + 交互债  
> 记录日期：2026-08-10  
> 状态：待讨论 / 待设计

---

## 问题 1：种子兑换完成后，种植动力断崖

### 现状

- 植物成长到 Lv5 收获 → 氛围+25 / 智慧之光+30 / 60% 种子
- 5 颗种子可兑换限定书籍：《绿野仙踪》《爱丽丝梦游奇境》
- 兑换完两本限定书后，种子失去明确用途

### 后果

- 中后期植物系统沦为**边缘玩法**：收益低、目标感消失
- 每日任务「浇水」变成机械操作，没有情感/策略回报
- 与核心循环（专注 → 智慧之光 → 买书/升级 → 访客叙事）断开

### 待探讨方向

1. **种子新出口**
   - 种子商店：兑换限定标志牌、场景装饰、BGM、皮肤
   - 声望/捐赠系统：种子作为图书馆声望消耗品
   - 访客礼物：特定角色喜欢特定植物/种子

2. **植物持续价值**
   - 成熟植物提供被动 Buff（专注速度 +1%、每小时微量氛围）
   - 植物作为视觉装饰，影响图书馆氛围
   - 植物组合触发访客评论或特殊事件

3. **循环与收藏**
   - 植物图鉴：收集全部品种/成熟形态
   - 季节/稀有种子轮换
   - 枯萎回收为肥料或素材

4. **与访客系统焊接**
   - 成熟植物吸引特定访客
   - 访客对植物发表评论（如谷雨已经 +30% 成长）
   - 特定植物 + 访客组合触发隐藏事件

## 问题 2：缺少植物废弃/移除按钮

### 现状

- 花盆种下后无法主动移除
- 玩家只能等 72 小时未照料后自动凋谢
- 凋谢后可能仍有残留状态，影响重新种植体验

### 需求

- 每盆植物增加「移除 / 废弃」按钮
- 点击后二次确认
- 废弃后可立即重新种植

### 待确认设计

- 废弃是否返还种子/肥料？返还比例？
- 是否需要消耗智慧之光或其他成本？
- 是否要有冷却期？
- 枯萎植物和正常植物在废弃时是否有差异待遇？
- 废弃动画/反馈如何设计？
