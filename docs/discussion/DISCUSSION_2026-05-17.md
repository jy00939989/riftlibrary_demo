## 新手引导 + 正向反馈改造方案

### 核心问题
- 当前 5 步引导卡信息过载
- 功能太多，新用户不知道要干什么
- 核心矛盾：希望用户感到放松，但实际体验是困惑

### 设计决策
- **不锁功能，锁节奏**——第一天全部功能开放，墨墨全程给"建议路线"
- 5 步引导卡缩减为 1 张，只告诉用户"第一件事是誊抄"
- 墨墨从只在计时中说话升级为全程旁白，关键节点弹对话
- 用户 20-30 分钟可串完核心循环（远在 Steam 2h 退款窗口内）

### 建议路线
```
PV → 1张引导卡 → 缮写室(专注) → 结算+成就 → 商店(升级) →
小王子完成 → 典藏证书+上架 → 访客 → 自由探索
```
