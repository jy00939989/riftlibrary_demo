# 归墟图书馆 · 异世界图书馆项目介绍

## 这是什么

一个纯前端网页游戏。你是一位在废墟中发现古老图书馆的人，通过专注誊抄、修复书籍、接待来自不同位面的访客，让这座被遗忘的图书馆重新活过来。

它把番茄钟专注计时器做成了一款有温度的游戏——你每专注一分钟，图书馆就复苏一点。没有竞技、没有排名、没有催促。只在你愿意坐下来的时候，陪你写一段字。

---

## 设计初衷

市面上的专注工具大多是冷冰冰的——计时器、白噪音、统计数据，用完了就关了。它们帮你计算时间，但不帮你记住时间。

我想要一个**留下来**的地方。你为它付出的每一分钟，都会变成书架上的一本书、窗台上的一盆植物、访客留言簿上的一句话。它不是一个工具，而是一个你在知识世界里拥有的角落。

核心情感：**守护与复苏**。你不是在"建造"什么，而是在慢慢修好一个本来就属于你的地方。

---

## 世界观

**归墟图书馆**坐落在世界之间的裂隙中，书架延伸向无尽的星海。

它连接着不同的位面——每一个位面都是一扇传送门，通往一个独立的、有完整故事线的世界。目前开启的是**星界·归墟**（图书馆本体所在的位面），后续将开启**田园瘟疫纪事**（一个中世纪瘟疫背景的叙事位面）以及更多。

访客们不是凭空出现的 NPC —— 他们是在各自真实的生活中推开了一扇不该存在的门，偶然走进来的。每个人都在自己的人生困境里，而图书馆成了他们暂时停下来、读一本书的地方。

---

## 核心玩法循环

```
坐下来 → 选一本书 → 专注誊抄（番茄钟）
    → 智慧之光（货币） + 氛围值（图书馆复苏度）
    → 买新书 / 升级设施 / 解锁位面
    → 吸引访客 → 借书 → 还书（带回事件和收藏品）
    → 氛围升级 → 图书馆视觉变化 → 解锁新内容
    → 继续坐下来
```

每一个环节都有一个情感锚点：**你的时间被认真对待了**。

## 功能模块概览

### 🖋️ 缮写室（专注系统）

核心体验。支持番茄钟（25分钟）和自由计时两种模式。选择一个章节开始誊抄时，屏幕上会出现羽笔书写动画——文字逐行在羊皮纸质感的背景上浮现。

缮写室可以升级（0→6级），从破旧角落逐步变成"缮写圣堂"。每级都有独立的插画和叙事文字。升级提升誊抄速度。

### 📖 大书库（书籍系统）

目前收录 24 本书，涵盖童话、寓言、小说、诗歌、哲学、历史、科学等类别。每本书有完整的章节结构，誊抄完成后解锁 mastery 等级（初识→传承，纯收集向成就）。

书籍来源：初始解锁 2 本 + 位面商店购买 17 本 + 访客好感度赠书 3 本 + 种子兑换 2 本（绿野仙踪、爱丽丝梦游奇境）。

### 🏛️ 馆长办公室（管理中枢）

五个子标签：
- **概况**：图书馆数据总览，氛围进度环，修改馆名
- **成就柜**：31 项成就，覆盖专注、书籍、访客、设施、收集五个维度
- **收藏室**：浏览已收集的信物、诗笺、照片、钥匙等
- **布置**：植物盆栽状态 + 种子库存 + 标志牌收集（5种）
- **馆长手册**：内置攻略和常见问题

### ☕ 读者沙龙（访客系统）

访客会在书架上浏览，借走你已完成的书籍。还书时带回智慧之光、氛围值，以及特殊事件——手写批注、诗笺、推荐书单、甚至一封未寄出的辞职信。

现有 4 位访客（沈明远、小萤、云游、阿九），全新 10 位访客已设计完成待实现：退休教授、焦虑程序员、倒闭书店老板、基层公务员、待业大学生、农村女孩、叛逆少女、内向富二代、大龄练习生、快递员诗人。每个人都带着自己的故事走进来。

### 🌌 位面商店（经济系统）

智慧之光的使用场景：
- **借阅区升级**（0→7级）：增加访客容量和还书收益
- **缮写室升级**（0→6级）：提升誊抄速率
- **馆内装潢**：植物盆栽（50💰）+ 标志牌（200~300💰）
- **新书购买**：从17本共享池中刷新
- **位面传送门**：解锁新的叙事位面

### 📜 馆史档案（记录系统）

两个子标签：馆史时间线（所有重要事件按时间排列）+ 墨墨日志（一只住在图书馆里的幽灵猫的每日回顾，它会用独特的视角总结今天发生了什么）。

### 🌍 位面系统（叙事引擎）

每个位面是一个独立的故事世界，有自己的角色、任务链、信物和结局。当前进度：
- 田园瘟疫纪事 Phase 1：5 位中世纪角色，小艾拉 Stage 1 的 4 条任务已完成框架搭建

### 🌱 植物盆栽

专注完成后获得浇水机会。植物 5 级成长（幼苗→小株→茂叶→含苞→绽放），可施肥加速。收获后凋谢回空盆，概率掉落种子。集齐种子可兑换女儿推荐的两本书。

### 📝 新手引导

10 步线性任务链（从"第一次打开图书馆"到"完成第一本书"），右下角挂件持续提示下一步，不催不赶。情境引导卡片在关键节点弹出（首次专注完成、首次访客到来、首次打开商店等）。

### 🎵 氛围与音乐

氛围值 0~500，分 5 个阶段（废墟→破败→陈旧→温暖→星辰）。每个阶段切换不同的图书馆背景图，并伴随升级弹窗叙事。3 层 BGM 系统根据氛围阶段交叉淡入淡出。

## 设计哲学

1. **时间是唯一的投入**：没有氪金、没有广告、没有社交压力。你愿意花时间，图书馆就会变好。
2. **静默叙事**：不说"你好棒"，而是在你修补好屋顶后，旁白写"雨水不再滴落在书页上"。
3. **访客是人，不是功能**：每个访客有自己的困境和故事。他们不是来给你任务的，是来坐一坐的。
4. **留白**：不是所有升级槽都要填满，不是所有成就都要做完。图书馆是可以发呆的地方。

## 技术事实

纯前端 Web 应用，原生 JavaScript ES Modules，Tailwind CSS 主题，localStorage 本地存档。无需服务器、无需安装、无需注册。一个 HTML 文件打开即用。

部署在腾讯云 EdgeOne Pages，代码托管 Gitee。
