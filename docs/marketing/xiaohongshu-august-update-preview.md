# 归墟图书馆 · 8 月更新预告 🌙

Hi 各位馆长好～

这个月归墟图书馆改了一大堆东西，我先挑重点给大家剧透一下，正式版很快会同步到线上 👇

---

## 🌿 植物系统大翻新

- 三条植物线各有 5 个成长阶段立绘，从嫩芽到盛花全程可见
- 鹤望兰 / 魔法玫瑰 / 星光蕨风格完全不同，一眼就能区分
- 收获、铲除、凋谢后统一显示空花盆，视觉更连贯
- 植物收获的氛围奖励已经过数值收紧，星辰之境不再来得太快

## 📚 书籍封面首批上线

- 26 本现有书籍已接入专属封面图
- 书架、完成证书、收藏馆都会显示封面
- 封面尺寸 512×768，竖版手绘风格，和羊皮纸 UI 统一

## 🏛️ 馆务系统更稳了

- 神模块拆分 Phase 1 已落地，代码结构更清晰
- Supabase 后端接入完成，后续可以云端存档
- 访客好感度 tick 持久化修复，数据不会再丢
- 借阅区等级现在会影响书籍损毁概率，升级真的有用

## 🔔 小细节也修了不少

- 引导任务widget不再崩溃
- 专注 BGM 移除， replaced by 环境音商店
- 导航栏手机适配完成
- 修复系统弹窗重做，奖励也做了平衡

## 🗓️ 还有我们的自用小工具

- Planner（项目规划器）已经剥离到独立目录，以后不会混进游戏 deploy
- 新增列表视图，筛选「已排期」终于能看到清单了
