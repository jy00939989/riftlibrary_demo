# 位面系统架构设计

## 一、概述

位面系统是归墟图书馆的扩展叙事层。玩家通过购买传送门解锁其他世界，异世界的角色将以访客身份来到图书馆，通过"留言簿"式信函交互委托任务。玩家完成誊抄等任务后回信提交，推进五位角色的个人任务线，最终汇聚为位面关键剧情。

### 设计原则

- **不打断专注** — 任务接取和提交均通过信函，不弹窗
- **访客是信使** — 玩家无法直接窥探位面，所有剧情由角色来访带出
- **群像叙事** — 五位角色个人任务线并行，收束于 stage 级关键事件
- **复用核心动词** — 任务以誊抄书籍为主，辅以种子收集等已有系统

| type | 说明 | condition |
|------|------|-----------|
| `copy_chapter` | 誊抄某书第N章 | `{ bookId, chapterIdx }` |

## 四、核心流程

### 4.1 位面解锁

```
购买传送门（位面商店）
  → state.quests.pastoral.unlocked = true
  → 第一位田园角色（小艾拉）立即加入来访队列
  → 艾拉首次到访 → 留下第一封信函
  → 位面页面角色卡片出现 ✉️ 未读徽章
```

### 4.2 任务生命周期

```
角色到访（定时 tick 或触发）
  ├─ 有可交付的新任务？
  │    → 留下任务信函 → 角色卡片 ✉️ +1
  ├─ 玩家已回信提交了任务？
  │    → 角色"收信"→ 任务完成 → 发放奖励
  │    → 留下感谢信/下一封任务信
  └─ 都没有？
       → 普通访客行为（浏览/借书/留下短笺）
```

### 4.3 Stage 推进

```
角色完成当前阶段全部任务
  → 该角色个人 stage +1
  → 检查：五位角色是否都 ≥ planeStage？
       → 是：planeStage +1
       → 生成 storyLog 关键事件条目
       → 下一批角色解锁（按 unlockStage 配置）
       → 可能解锁信物/信件
```

### 4.4 角色解锁节奏

| Plane Stage | 解锁角色 | 叙事锚点 |
|-------------|---------|----------|
| 1 | 小艾拉 | 女孩误入图书馆 |
| 1 | 玛格丽特 | 草药师在找助手 |
| 2 | 卡特琳 | 修女质疑信仰 |
| 3 | 艾德里安 | 学者发现禁书真相 |
| 4 | 杜兰伯爵 | 领主面对后果 |
| 5 | 五人齐聚 | 交叉任务，共同叙事 |
