# UI 截图审计

> 日期: 2026-05-18 | 审计者: Claude Code + gsp-screenshot-critic
>
> 评估项目: 异世界图书馆 (library_demo)
>
> ⚠️ 注意: 本次审计因运行环境限制未能直接查看截图，基于 CSS 源码、渲染逻辑和素材结构推断。置信度标注为 medium。

---

## 确认的优势

| 发现 | 证据 | 置信度 |
|------|------|--------|
| **主题一致性高** | CSS 变量系统：`parchment`/`ink`/`wood`/`magic-gold`/`magic-blue`，全站统一的羊皮纸魔法风格 | high |
| **导航视觉分层清晰** | 三态按钮（默认半透明→悬停微光→激活金色底线），page-enter 淡入动画 0.35s | high |
| **稀有度视觉区分** | 成就卡片 4 级差异：青铜(琥珀)/白银(灰)/黄金(黄+glow)/铂金(紫+强glow) | high |
| **背景动态变化** | 5 张背景图随氛围切换（废墟→华丽），body 固定 background-attachment | high |
| **书籍卡片有设计感** | 书脊式竖卡（封面区+书脊区），hover 微光效果 | medium |
| **弹窗动画讲究** | `animate-scale-in` + `magic-glow` + 淡出过渡，关闭时 opacity 0.3s | high |

## 确认的问题

| 发现 | 严重度 | 证据 | 置信度 |
|------|--------|------|--------|
| **移动端自适应缺失** | 🔴 严重 | 成就网格 `grid-cols-4 sm:grid-cols-5 md:grid-cols-6`——小屏仍 4 列，成就卡片会很挤 | high |
| **音乐按钮无状态视觉反馈** | 🔴 严重 | 恒为 `🔈`，`toggleMusic()` 不改变图标，用户无法知道当前是开是关 | high |
| **馆长办公室子标签行可能溢出** | 🔴 严重 | 5 个子标签每个 `px-5`，在小屏幕上会挤在一起 | medium |
| **书籍选择器是原生 `<select>`** | 🟡 建议 | 在羊皮纸魔法主题中，浏览器默认下拉框会破坏沉浸感 | high |
| **缮写室非活跃状态全量 DOM 重建** | 🟡 建议 | `renderFocusPage()` 在大多数情况 `container.innerHTML = ''` 后重建全部 DOM | high |
| **羊皮纸纹理是纯 CSS 模拟** | 🟡 建议 | `.grain-texture` 是空 div，没有实际的噪点纹理图 | medium |

## 推断的风险

| 风险 | 说明 | 置信度 |
|------|------|--------|
| 弹窗链叠加可能视觉混乱 | `handlePostFocusEffects` 的回调链叠 5+ 层弹窗，每层 z-index 都可能冲突 | medium |
| 浅色背景阶段对比度下降 | body 背景叠加 `rgba(44,36,25,0.88)` 图片——温暖/星辰阶段白色卡片与浅色背景对比度可能不足 | low |
| toast 可能在弹窗链中被遮挡 | 成就 toast 用 setTimeout 弹出，若与结算弹窗重叠会在下层不可见 | medium |
| 大书库长列表滚动体验 | 24 本书全部显示，只有筛选没有分页，信息密度不均 | medium |

## 修复优先级

| 优先级 | 问题 | 建议 | 改动量 |
|--------|------|------|--------|
| **P0** | 音乐开关无状态视觉 | 图标切换 `🔈`↔`🔇`，在 `toggleMusic()` 中更新 DOM | ~5 行 |
| **P0** | 原生 `<select>` 破坏沉浸感 | 换成自定义下拉，Tailwind 组件样式即可 | ~30 行 |
| **P1** | 移动端响应式 | 导航在小屏改为可滚动横条或汉堡菜单 | ~50 行 CSS |
| **P1** | 弹窗 z-index 管理 | 建立 z-index 层级规范，用 CSS 变量统一管理 | ~20 行 |
| **P2** | 缮写室全量重建性能 | 活跃状态下避免整页 `innerHTML = ''`，改用 DOM 局部更新 | ~40 行 |
| **P2** | 子标签可发现性 | 给子标签加图标提示或悬停预览 | ~20 行 |

## 总评

整体视觉系统设计是这项目最强的部分——魔法羊皮纸主题、氛围驱动的背景切换、三态导航按钮、书籍书脊卡片，调性统一且有辨识度。Tailwind + CSS 变量的组合用得很高效。

但有几个硬伤：音乐开关不可见、原生 select 破坏沉浸感、移动端没有做响应式。前两个改起来成本很低（各 5-30 行代码），回报很高。建议本迭代优先修复 P0 项。
