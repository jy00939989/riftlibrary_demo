# UX 流程与导航审计

> 日期: 2026-05-18 | 审计者: Claude Code + gsp-ux-flow-audit
>
> 评估项目: 异世界图书馆 (library_demo)

---

## 首 30 秒体验

```
打开页面 → 废墟背景 3秒 → PV视频(可选) → 5张引导卡片 → 回到缮写室
```

| 发现 | 问题 |
|------|------|
| 3 秒空白等待 | 加载画面无任何提示，用户不知道发生了什么 |
| 视频点播放按钮很大 | 但"双击可跳过"文字太小，大部分人会等视频播完 |
| 5 张引导卡片全是纯文字 | 每张约 150 字，用户被动阅读，没有任何交互式"试一下"环节 |
| 卡片自动切换背景标签页 | 用户看不见背景在换，引导和实际操作完全脱节 |

## 导航结构

```
🖋️ 缮写室    📖 大书库    🏛️ 馆长办公室    ☕ 读者沙龙    📜 馆史档案    🌌 位面商店
  主页面       单页      5个子标签          单页         2个子标签       单页
```

| 发现 | 问题 |
|------|------|
| 馆长办公室有 5 个子标签 | 概况/成就柜/收藏室/布置/馆长手册——只有点了才知道里面有什么 |
| "布置"子标签实际是 植物+种子+标志牌 | 名字不直观，用户预期是"装修"而非"园艺" |
| 馆史档案的子标签 `馆史/墨墨日志` | 墨墨日志是 AI 生成的每日回顾，功能很好但导航层级太深 |
| 导航按钮样式不错 | 三态（默认/悬停/激活）+ 金色底线，但 emoji 名称偏文艺，功能性提示不足 |

## 核心 Verb 可发现性

```
用户落地 → 看到缮写室 → 模式选择器(3种) → 书籍选择器 → 开始专注
```

- ✅ 默认 1 分钟倒计时——降低首次门槛
- ❌ 新用户同时面对 3 个决策：选模式？选书？设时长？——在体验核心循环之前就被选项淹没了
- ❌ 初始只有 2 本书可选（小王子/动物农场），但用户看不到"为什么只有 2 本"以及"怎么获得更多"

## 流程摩擦点

### 1. 专注完成后的弹窗链太长

```
完成专注 → 典藏证书 → 上架动画 → 章节解锁 → 里程碑 → 结算卡片
              ↑ 每个都必须点一下才能到下一个
```

首次完成一本书时，用户要连点 5-6 个弹窗才能回到主界面。

### 2. 暂停/恢复交互脆弱

暂停和恢复是同一个按钮，视觉上只有一个图标变化。用户无法一眼判断当前是暂停还是运行中。

### 3. 没有"现在我该做什么"的指引

引导结束后，用户被丢回缮写室。今日馆务卡片提供了一些方向，但它只是页面顶部的一小块。如果没有主动切换到商店/访客页面，用户可能不知道这些系统存在。

### 4. 收集品反馈路径过长

获得成就 → toast 弹出 0.5s → 想看清楚要去 馆长办公室 → 成就柜子标签。中间隔了 2 层导航。

### 5. 音乐开关状态不可见

图标永远是 🔈，开了和关了没有视觉区别，只能靠耳朵判断。

## 打分

| 维度 | 评分 | 说明 |
|------|------|------|
| 首次可操作屏幕 | ⭐⭐ | 被视频+5张卡片挡了 30-120 秒 |
| 引导长度/打断成本 | ⭐⭐ | 纯被动阅读，无交互式教学 |
| 主 Verb 可发现性 | ⭐⭐⭐⭐ | 落地即见，但选项过多 |
| 暂停/恢复/重试流 | ⭐⭐ | 一个按钮管所有状态，不可区分 |
| 页面切换体验 | ⭐⭐⭐ | 有淡入动画，但切换后无上下文继承 |
| 子标签可发现性 | ⭐⭐ | 藏在按钮行里，无预览无提示 |
| 完成→继续循环 | ⭐⭐ | 弹窗链太长，打断节奏 |

## 总评

引导做得很用心（PV + 5 步 + 氛围弹窗 + 升级弹窗），但引导和实际操作是两层皮——用户看了很多字，却没有在引导中真正"做"一次专注。导航层级的复杂度和标签命名风格偏重氛围，牺牲了信息可扫描性。建议优先：缩短引导到 3 步并加入交互环节、合并子标签减少导航深度、给音乐开关加状态图标。
